# 컨텍스트 노트 — 실시간 장중 곡선 표기 통일 (2026-07-30)

## 왜 미국 상세만 꽉 찼나

`web/assets/stocks.js`의 `px2()`가 미국일 때만 `(tsv[i]-wlo)/(whi-wlo)`로 **데이터 범위 정규화**를
쓰고 있었다(`wlo=min(ts)`, `whi=max(ts)`). 국내는 `t2x()`가 09:00\~15:30을 고정 프레임으로 잡아
처음부터 진행형이었다. 그래서 같은 코드베이스인데 국내는 맞고 미국만 틀린 상태였다.

미국을 epoch 기반으로 배치한 원래 이유는 "KST 자정 넘김에도 정렬 안정"인데,
그 목적은 프레임을 고정해도 그대로 유지된다 — 분모만 세션 길이로 바꾸면 된다.

## 세션 프레임을 epoch로 역산한 이유

미국 세션 경계는 ET 분(프리 240\~570, 정규 570\~960, 애프터 960\~1200)으로 정의돼 있는데
x축 배치는 epoch로 한다. 그래서 `usSegWindow(seg, anchorTs)`가 **데이터 한 점의 epoch와
그 시점의 ET 분**으로 세션 시작 epoch를 거꾸로 계산한다.

`anchorTs`로 `tsv[0]`(그 세션 첫 봉)을 쓴다. 세션 도중에는 DST 전환이 없으므로
`start = anchorTs - (etMin(anchorTs) - segLo) * 60`이 정확하다.
프리장 첫 체결이 04:00보다 늦어도(예: 06:00) 시작점은 여전히 04:00으로 잡히는데, 이게 맞다 —
"프리장이 얼마나 진행됐나"가 기준이지 "데이터가 언제부터 있나"가 아니다.

## x축 라벨을 세션 경계로 바꾼 이유

기존엔 데이터의 시작/중간/**마지막** 시각을 찍었다. 프레임을 고정해놓고 오른쪽 끝에
마지막 체결 시각을 그대로 두면 "장이 여기서 끝났다"로 읽혀, 진행형 곡선과 정면으로 어긋난다.
그래서 프레임 시작·중간·끝(KST)으로 바꿨다. 정규장이면 22:30 / 01:45 / 05:00.

## 맥동 도트 — 화면마다 구현이 다른 이유

같은 규격이지만 SVG 좌표계가 달라서 그리는 방식이 다르다.

- **카드형(홈·섹터 페이지)**: SVG가 `preserveAspectRatio="none"`이라 가로만 늘어난다.
  SVG 안에 `<circle>`을 넣으면 타원으로 찌그러진다 → SVG 밖의 HTML `<span>`(고정 px) + CSS
  `@keyframes sparkdotpulse`.
- **상세 페이지**: `intra-svg`는 `preserveAspectRatio` 기본값(`meet`)이라 가로세로 비율이
  유지된다 → SVG 안 `<circle>` + SMIL `<animate>`로 충분하다.

상세 페이지에 SMIL을 쓴 실질적 이유가 하나 더 있다. 상세 페이지는 `/assets/stocks.css?v=4`로
버전 쿼리가 박혀 있어 CSS를 고치면 **생성된 HTML 50여 장을 전부 재생성**해야 반영된다.
반면 `/assets/stocks.js`는 쿼리가 없어 파일만 바꾸면 모든 상세 페이지에 즉시 반영된다.
SMIL로 처리하면 JS 한 파일 변경으로 끝난다.

## 섹터 페이지는 재생성이 필요하다

`drawSpark`가 `scripts/templates/pages/stock_sector.html`에 인라인으로 들어 있어
`python3 scripts/generate_html.py --sectors`로 8개 페이지를 다시 구워야 반영된다.
홈(`stocks-home.js`)은 외부 JS라 재생성 불필요, 상세 페이지도 `stocks.js`라 불필요.

## 손대지 않은 것

- `stocks-home.js` `sbxSpark` — 이번 규격의 **기준 구현**이라 그대로 뒀다.
- 장중 고점/저점 라벨이 곡선과 겹쳐 보이는 문제 — 곡선 폭이 좁아지면서 눈에 띄지만
  라벨 배치 로직(`labelTxt`)은 이번 변경 이전과 동일하다. 요청 범위 밖이라 건드리지 않았다.
- `data/news_summary_kospi.json`·`data/catalyst_history_kospi.json` — 작업 중
  로컬의 다른 프로세스가 00:00:15에 덮어썼다. 이 작업과 무관해 커밋에서 제외했다.
