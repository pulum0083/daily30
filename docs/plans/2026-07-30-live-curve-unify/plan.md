# 실시간 장중 곡선 표기 통일 (2026-07-30)

## 문제

`/stocks/us/nvda/`의 "오늘 장중" 곡선이 **장 시작 1시간 반 시점인데도 차트 폭을 꽉 채워** 그려졌다.
x축을 세션 전체가 아니라 **수집된 데이터 범위**(첫 봉~마지막 봉)로 정규화하기 때문이다.
그래서 09:35 ET든 15:59 ET든 곡선 모양이 똑같이 "하루 다 끝난 그림"으로 보이고,
사용자는 지금 장이 어디까지 진행됐는지 화면에서 읽을 수 없다.

이미 홈(`/stocks/`)의 섹터별 종목 카드는 이 문제를 푼 구현(`sbxSpark`)을 갖고 있는데,
상세 페이지·섹터 페이지가 그 규격을 따르지 않아 화면마다 곡선의 의미가 다르다.

## 목표 — 실시간 곡선 규격 통일

기준 구현은 홈 섹터 카드(`web/assets/stocks-home.js` `sbxSpark`). 모든 실시간 곡선이 아래를 따른다.

1. **x축 = 세션 고정 프레임.** 데이터 범위가 아니라 세션 전체 길이를 폭으로 잡아,
   경과한 만큼만 곡선이 채워진다.
   - 국내: KST 09:00~15:30
   - 미국: 현재 세션 구간 — 프리 04:00\~09:30 / 정규 09:30\~16:00 / 애프터 16:00\~20:00 (ET)
2. **곡선 끝 → 오른쪽 끝까지 점선 가이드** (장중일 때만). "여기까지 진행 중"을 드러낸다.
3. **곡선 끝점에 맥동하는 라이브 도트** (장중일 때만). 마감 후에는 기존 정적 끝점 유지.
4. **x축 라벨 = 세션 시작/중간/끝 고정 시각.** 데이터 마지막 시각이 오른쪽 끝에 붙지 않는다.

## 적용 대상

| 파일 | 화면 | 할 일 |
| --- | --- | --- |
| `web/assets/stocks.js` | `/stocks/{code}/`, `/stocks/us/{ticker}/` 오늘 장중 | 미국 x축 고정 프레임화 + 양쪽에 점선 트레일·라이브 도트 |
| `scripts/templates/pages/stock_sector.html` | `/stocks/sector/{key}/` 카드 | `drawSpark`에 진행형 채움 + 라이브 도트 |
| `web/assets/stocks-home.js` | 홈 섹터 카드 | **변경 없음** (기준 구현) |
