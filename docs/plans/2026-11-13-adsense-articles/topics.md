# 해설 글 주제 목록 — 애드센스 재신청 준비 (2026-11-13)

## 왜 쓰나

- 2026-11-04 애드센스가 "가치가 별로 없는 콘텐츠"로 거절했다(§80).
- 그때 사이트의 90%가 매일 같은 틀의 짧은 자동 생성 브리핑이었다. 30일 지난 브리핑은 noindex로 돌렸다(§33).
- 남은 숙제는 오래 남는 해설 글을 쌓는 것이다. 다른 사이트에 없는 이 사이트만의 자료를 쓴다. 매일 채점한 예측 기록과 직접 돌린 백테스트, 그리고 데이터 사고에서 알아낸 사실들이다.

## 원칙

- 숫자는 전부 저장소의 파일·스크립트에서 가져온다(§0·§20). 글에 쓴 숫자 옆에 출처 파일을 남긴다.
- 기대만큼 안 나온 결과도 그대로 쓴다(월봉 5개월선 49.6% vs 50.4%처럼). '추천'·'수익 보장'처럼 들리는 말은 쓰지 않는다.
- 한 편 2,000자 이상, 직접 그린 그래프나 표를 1개 이상 넣는다.
- 초안은 AI가 쓰더라도 **운영자의 관점 한 단락**을 꼭 넣는다. 왜 이 지표를 만들었는지, 직접 겪은 일 같은 것이다. 이게 자동 생성 글과 갈리는 지점이다.
- 제목은 사람들이 실제로 검색하는 말로 시작한다.

## 제안하는 순서

1. ★ 표시한 1~3번을 먼저 쓴다. 1번은 사이트 전체의 신뢰를, 2번은 어디에도 없는 실측 발견을 보여 준다. 3번은 검색 수요가 큰 주제다.
2. 2~3주 안에 10편 정도 쌓이면 애드센스를 다시 신청한다.
3. 글은 `/guides/{주제}/` 같은 영구 주소에 두고, 사이트맵·푸터·관련 장기 지표 페이지에서 링크한다. 주소 구조와 화면 모양은 첫 글을 쓸 때 정한다.
