# 섹터 가중 교정 + 홈 정리

## 1. 섹터 평균이 지수와 모순되는 문제

2026-08-21 홈 화면에서 `🔬 반도체 -2.78%`가 떴는데, 같은 화면의 주도주 카드는
삼성전자 `+3.87%` · SK하이닉스 `+2.31%`였고 코스피는 `+0.88%`였다.
8개 섹터 중 7개가 하락 표기라 지수 방향과 정반대로 읽혔다.

### 원인

`secBuildSectorData()`(stocks-home.js) · `sectorAverages()`(_signals-core.mjs) 모두
대표 5~7종목의 **단순평균**이다. 반도체는 삼성전자·SK하이닉스가 섹터 거래대금의 **97%**인데
단순평균은 이 둘을 소형주와 똑같이 1/7씩 취급한다.

```
반도체 (2026-08-21)
  삼성전자      +3.87%   거래대금 77,897억  ┐ 둘이 151,377억
  SK하이닉스    +2.31%   거래대금 73,480억  ┘ = 섹터의 97%
  주성엔지니어링  -4.91%   거래대금  1,336억
  한미반도체     -5.32%   거래대금  1,100억
  DB하이텍      -7.43%   거래대금    551억
  이오테크닉스    -2.53%   거래대금    403억
  리노공업       -5.47%   거래대금    224억
```

### 시총가중을 못 쓰는 이유

발행주식수가 **어느 소스에도 없다**. 스냅샷 필드에 없고(`change_pct·close·vol·ma200·
foreign_rate…`), `toss_client.py`는 캔들·현재가·환율만 제공하며, 네이버
`api.stock.naver.com/stock/{code}/integration`은 **409 Conflict로 차단**된다.
네이버 업종 지수(`sise_group.naver`)는 79개 업종이라 이 서비스의 8개 커스텀 섹터와
1:1 매핑이 안 된다 — 별도 프로젝트 규모.

### 채택: 거래대금 가중

`종가 × 거래량`은 **스냅샷에 이미 있는 실측**이다. 없는 실측(시총)을 지어내지 않고
있는 실측으로 근사한다(§0). 코드에 이미 선례가 있다 —
`secBuildSectorData`의 `dvol`이 "섹터 크기" 대용으로 같은 값을 쓰고 그 근거를 주석에 적어뒀다.

검증 결과 **반도체만 부호가 뒤집히고(-2.78% → +2.92%) 나머지 7개 섹터는 부호 유지**한다.
즉 정상 케이스를 흔들지 않고 깨진 케이스만 고친다.

| 섹터 | 단순평균 | 거래대금가중 |
| --- | --- | --- |
| semicon | -2.78% | **+2.92%** ← 부호 반전 |
| finance | +3.96% | +6.06% |
| auto | -1.99% | -1.21% |
| bio | -1.43% | -2.42% |
| battery | -4.18% | -4.02% |
| ship | -3.95% | -4.25% |
| power | -4.18% | -4.55% |
| defense | -6.80% | -8.30% |

### 범위

- `_signals-core.mjs sectorAverages()` — `wavg`(거래대금 가중) 추가. `amount` 없으면 단순평균 폴백.
- `stocks-home.js secBuildSectorData()` — `wavg` 추가, 칩·통계 박스가 이를 사용.
- 라벨을 사실대로 — "섹터 평균" → "거래대금 가중".
- `avg`(단순평균)는 제거하지 않는다. 다른 소비처가 있고, 폴백 경로로도 필요하다.

## 2. 홈 죽은 마크업 · 중복 호출

- `#income` 블록 17,217 bytes(홈 HTML의 29%) — 월배당을 `/stocks/income-designer/`로
  이관한 뒤 원본이 남았다. `#income` 링크 0건 · 토글 JS 0건이라 **도달 경로가 없다**.
- 홈 1회 로드에 같은 엔드포인트가 중복 호출된다
  (`/api/market` 5회, `/api/stocks-live?us=` 4회, `stocks-snapshot.json` 3회, `/api/intraday` 7종목×2회).
  Vercel 함수 비용의 직접 원인.

### 범위

- `#income` 블록과 그 전용 CSS·JS(도달 불가한 것만) 제거.
- 중복 호출은 **호출부를 지우는 게 아니라** 인플라이트 공유(dedupe)로 해결한다 —
  호출부를 지우면 어느 위젯이 그 데이터를 잃는지 추적하기 어렵고 회귀 위험이 크다.
