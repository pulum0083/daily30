# 결정 노트 — 예측 성적표·방법론 페이지

- **왜**: 애드센스 "가치가 별로 없는 콘텐츠"(2026-11-04). 매일 자동 생성되는 짧은 브리핑과 숫자판 위주라 고유한 글이 적었다. 이미 가진 고유 자료(채점 기록·백테스트)를 글로 푼다.
- **새 페이지로**: 기존 페이지를 늘리지 않고 `/accuracy/`·`/methodology/`를 새로 만든다. 사용자 확인(2026-11-05).
- **머리 메뉴엔 넣지 않음**: 휴대폰에서 좁아진다. 푸터·브리핑 성적표 카드·서비스 소개로 충분히 닿는다.
- **숫자를 코드에 박지 않음**: 코스피 백테스트 결과는 그동안 주석·문서(§57)에만 있었다. 다시 돌리니 숫자가 달라졌다(713일 72.5% → 728일 72.8%, 분해 115일 → 116일). 스크립트가 파일을 쓰고 페이지가 그 파일을 읽게 했다.
- **빠진 숫자**: 미국 'SOX·VIX를 섞으면 57.7%', 'AI가 계산을 뒤집은 날 더 틀렸다(73.5% vs 68.2%)'는 파일에 없어 문장만 남기고 숫자는 뺐다.
- **실패 시**: 성적표 갱신이 실패하면 직전 페이지가 남는다. 페이지에 기준 날짜가 보여 멈추면 드러난다 — 별도 알림은 두지 않았다.
