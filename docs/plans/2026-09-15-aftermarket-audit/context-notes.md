# 애프터장 가격 잔존 경로 감사 — 컨텍스트 노트

## 측정 (2026-09-15 오전, 9/14 과거 데이터)

- 네이버 일봉·fchart 일봉·siseJson·sise_day·pykrx 모두 9/14 SK하이닉스 종가 1,683,000 / 거래량 4,001,549로 같다.
  야후 `.KS`만 종가가 공식(1,697,000)이고, 거래량은 야후도 4,001,549다. **정규장 거래량을 주는 일봉 소스는 없다.**
- 1분봉 거래량(`accumulatedTradingVolume`)은 이름과 달리 봉 단위 거래량이다. 9/14 SK하이닉스는 09:00~15:30 합
  3,742,905 + 15:31~15:59 957 + 16:00~ 256,370 ≈ 일봉 4,001,549.
- 9/11(애프터장 이전) 일봉 거래량과 09:00~15:30 1분봉 합의 차이는 0.04~0.2%(시간외 거래분). 그래서
  9/14 이후 봉을 정규장 1분봉 합으로 바꿔도 과거 봉과 정의가 사실상 같다.
- 9/14 애프터장 거래량 비중: 삼성전자 6.7%, SK하이닉스 6.4%, 현대차 5.8%, 한미반도체 20.1%, 한화에어로 2.5%,
  LG엔솔 2.9%, KB금융 1.9%.
- 코스피 지수는 영향 없음 — 9/14 지수 1분봉이 15:32에 멈추고 일봉 종가 6684.37과 같다.
- integration PER은 EPS가 그대로인데 75초 사이에 값이 바뀐다(실시간 가격 기반, 약간 지연). 삼성전자 PER 11.15 =
  248,500 / EPS 22,292 — 반올림된 EPS로도 PER이 정확히 재현된다.
- 마감 브리핑 프롬프트는 `latest_kospi_close.json` 전체를 넣는다(`call_claude` 1845) — 렌더되지 않는
  `kospi200_top10`·`ai_semicon_stocks`도 모델 입력이다.
- 1분봉 한 날짜 09:00~15:30 응답 약 64KB, 직전 거래일 15:30~당일 15:30 창도 약 65KB. 7일 창은 340KB.

## 결정

- 정규장 거래량은 1분봉 합으로 정의하고, 종가와 같은 저장소(`data/kr_official_closes.json`)에 `volumes`로 쌓는다.
  1분봉 조회 기한(약 7거래일)이 지나면 복구할 수 없는 것도 종가와 같다.
- 일봉의 시가·고가·저가도 오염돼 있지만(9/14 저가 1,678,000 vs 정규장 1,686,000) 이 행을 읽는 소비처가 없어
  교정하지 않고 docstring에 명시한다.
