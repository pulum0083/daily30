# 방문자 늘리기 — 코드로 할 수 있는 4가지 (2026-10-27)

목표: 하루 방문자 1천 명(현재 약 20명, 텔레그램 구독 30명).
코드로 바로 할 수 있는 4가지를 사용자가 정한 순서대로 한다.

1. **브리핑 페이지 제목** — `날짜 + 고정 문구`를 `검색어 + 날짜 | 헤드라인`으로 바꾼다.
   이미 발행된 브리핑도 `<head>`의 제목·설명 줄만 고친다(본문은 건드리지 않는다, §33).
2. **브리핑 끝 구독 입구** — 본문 끝(광고 앞)에 텔레그램 구독 안내를 둔다.
3. **네이버 정비** — 브리핑 RSS 피드를 만들고, 인증 태그가 없는 `/stocks/`에 태그와 RSS 링크를 넣는다.
   서치어드바이저 제출은 사용자가 직접 한다.
4. **공유용 카드 이미지** — 브리핑마다 og:image(방향·확률 + 헤드라인) PNG를 만든다.
   텔레그램은 이미 `prefer_small_media`라 작은 썸네일로 뜬다.

순서: 1 → 3(구독 입구) → 2(네이버) → 4.
