# 종목 시그널 첫 페이지(/stocks/) 개편 — 계획 (2026-10-26)

프로토타입 `docs/prototypes/2026-10-25-stocks-home-redesign.html`, 빌더 `build_proto.py`(참고용). doubleshot.space/ → /stocks/ 로 넘어오는 사이트 현관.

## 왜
- 모바일 5,091px로 길고, 맨 위 제목("어제랑 비교해서")이 하루 대부분 맞지 않는다.
- 현관인데 브리핑으로 가는 길이 약하다(브리핑 스트립 한 줄). 특이신호는 탭 뒤, 상세 페이지 없는 종목은 눌러도 막힌다.
- 목표: 시간대마다 모바일 약 1,300~1,400px.

## 시간대(KST) — `homeSlot()` 하나가 판정
| 시각 | 카드 | 데이터 |
| --- | --- | --- |
| 평일 07:30~09:00 | 코스피 시초가 예측 | 오늘 kospi 스냅샷(예측·view_title·dek) + accuracy-summary(시초가 적중) |
| 09:00~15:30 | 어제랑 비교 곡선(기존 대결판, §49·§54 그대로) | /api/intraday?vs=intraday |
| 15:31~미국 브리핑 발행 전 | 코스피 마감 — 마감 브리핑이 ready 전이면 기존 마감 곡선(§54) | 오늘 close 스냅샷(market_title/reason_title·dek) + home-summary(아침 예측 채점) |
| 미국 발행 후~다음 날 07:30 | 미국 브리핑 | 그날 us 스냅샷(큰 쪽 확률·view_title·dek·나스닥 체크) |
| 주말·휴일 | 이번 주 정리 | home-summary(주간 등락·이번 주 성적) + stocks-snapshot(섹터 주간) |
- 오늘 브리핑이 ready가 아니면 옛 날짜로 대체하지 않고 카드를 뺀다(§13·§16). 한국 휴장일엔 코스피 카드를 빼고 미국 카드는 KST 평일이면 보여준다.
- 개발용 `?slot=`·`?d=` 쿼리(무해 — 표시만 바꾼다).

## 단계(단계마다 테스트·커밋)
① 시간대 카드(브리핑 스트립·맨 위 제목 대체) ② 특이신호 상위 3 홈 노출 ③ 주도주·섹터 압축 ④ 밤사이 미국 두 묶음
⑤ 구조 신호 ⑥ 주말 이번 주 정리 ⑦ 넓은 화면 1단 다듬기

## 지킬 것
숫자는 실측, 헤드라인·dek는 스냅샷 그대로(새 문장 금지), 주말 헤드라인은 일별 등락 나열(결정론). 라우트 추가 금지(11/12).
공개 JSON에 없는 값은 마감 잡이 만드는 정적 JSON(`web/data/home-summary.json`, 주인 하나 §18). 대결판 규칙(§49·§54) 유지.
상세 페이지 없는 종목은 섹터 페이지로(§36). 텔레그램 발송 없음. 푸시는 사용자 지시 시, 잡 시간 피해서.
