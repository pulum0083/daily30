# 중간선거 해 비교(2018 vs 2026) — 검토·시안 기록 (2026-11-15)

사용자 요청: 종목 홈 장기 신호의 코스피 체크를 완전히 빼고, '트럼프 1기 중간선거 뒤와 닮았을까' 비교 지표를 넣는다.
2018년 선은 2019년 말까지 그린다. 상세 페이지도 만든다.

## 데이터로 확인한 것 (2026-11-13 종가)
- S&P 500 연초 대비: 2026 +10.5%(고점 10/6 +14.2%) / 2018 같은 날 +1.8%(고점 9/20 +9.6%, 12/24 −12.1%, 연말 −6.2%) / 2019 +28.9%(나스닥 +35.2%)
- 두 해 곡선 상관 0.59(나스닥 0.68), 일간 등락 상관 0.10 — 큰 줄기만 비슷하다.
- 그해 고점 대비: 2018-11-13 −7.1% / 2026-11-13 −3.3%. 2018 고점→12/24 −19.8%.
- 10년물: 2018-11-13 3.14% / 2026-11-13 5.15%. 2026 첫 5% 이상 종가 9/16, 최고 5.31%(10/5).
- 기준금리 상단(FRED DFEDTARU): 2018 3/22·6/14·9/27 인상(→2.25), 12/20 2.5 → 2019 8/1·9/19·10/31 인하. 2026 9/17 3.75→4.00 인상(9/16 FOMC).
- 중간선거 19번(1950~2022) 선거일 뒤 12개월 S&P 500: 19/19 상승, 평균 +15.1%, 최저 +1.1%(1986). 아무 날 12개월 뒤 상승 74.7%, 평균 +9.4%.

## 이미지(유튜브 캡처) 사실 확인
- "2018년 10월 10년 금리 첫 3% 돌파" — 틀렸다. 첫 3% 종가는 2018-04-25. 10~11월은 7년 만의 최고(3.23%, 11/8).
- "2026년 9월 10년 금리 첫 5% 돌파" — 맞다(9/16).
- 2026 '민주당 탈환'·워시 발언 인용은 원문 확인 전엔 쓰지 않는다(§0). 시안 사건 목록엔 넣지 않았다.
