# 애드센스 준비 — 서비스 개선안 (2026-09-02)

외부 LLM(제미나이) 진단을 받았으나 **사이트 밖에서 본 추정**이라, 실제 발행물·코드와
대조해 사실 관계를 먼저 확정했다. 결과적으로 진단의 절반가량이 실제와 달랐고,
그에 따라 우선순위가 크게 바뀐다.

---

### 진단이 놓친 것

- **`/` 루트가 리다이렉트 스텁인데 sitemap 1순위(priority 1.0)로 등재돼 있다.**
- **`/about/`, `/legal/*` 4개 페이지가 sitemap에 없다** — 심사관이 가장 먼저 찾는 페이지들이다.
- **`scripts/templates/pages/briefings_index.html`(아카이브 목록 템플릿)이 살아 있으나
  어느 코드 경로에서도 렌더되지 않는 죽은 템플릿이다.** 2026-07-22에 리다이렉트 스텁이
  덮어썼다(SERVICE_RULES §10과 같은 계열 — 문서·템플릿이 코드보다 오래 사는 상황).

### 핵심 통찰 — ③이 ①의 원인일 가능성

진단이 "브리핑이 thin하다"고 본 이유는, **허브에서 막혀 본문에 도달하지 못했기 때문**일
수 있다. 실제 브리핑은 4,600자다. 즉 **가장 싸게 고칠 수 있는 항목(허브)이 가장 큰
오해를 만들고 있다.** 여기부터 손대는 게 비용 대비 효과가 가장 크다.

## 2. 우선순위별 개선안

### Tier 1 — 확실한 결함. 사용자 가치도 함께 오른다

**T1-1. `/briefings/`를 정적 아카이브 목록으로 전환 (리다이렉트 제거)**
현재 79편이 발행돼 있는데 **과거 브리핑을 훑어볼 경로가 사실상 없다**(목록은 최근 20일,
그마저 허브는 리다이렉트). 크롤러 문제이기 이전에 **실사용자 문제**다.
- `web/briefings/index.html` 스텁 → `briefings_index.html` 템플릿 기반 SSG로 복원
- 날짜별 카드 + 각 브리핑의 제목/요약 한 줄을 정적 HTML로 출력(내부 링크 확보)
- `build_list_context`의 `past_dates[:20]` → 월별 그룹 전체 아카이브로 확장

**T1-2. sitemap 정리**
- `/about/`, `/legal/disclaimer/`, `/legal/privacy/`, `/legal/terms/` 추가
- `/`(리다이렉트 스텁) 등재 재검토 — 실제 도착지를 등재하거나 스텁 자체를 없앤다
- 구현: `generate_html.write_sitemap_xml()`

**T1-3. 섹터 페이지 본문 보강 (980자 → 1,500자+)**
8개 섹터 각각에 "이 섹터를 무엇으로 보는가"를 2~3문단. 이미 있는 섹터 정의·편입 기준을
글로 풀면 된다 — 없는 내용을 지어내는 게 아니다.

### Tier 2 — YMYL 정책 리스크 완화

**T2-1. 종목 픽의 진입/목표/손절 표기 재검토**
심사관에게 **금융 라이선스 없는 매매 신호**로 읽힐 수 있는 가장 큰 요소다. 선택지:
(a) 문구를 "참고 범위"로 바꾸고 산출 근거(20일 이평·ATR 등)를 함께 노출
(b) 카드 안에 명시적 면책을 붙인다(현재 면책은 섹터 각주 한 줄뿐)
(c) 그대로 두되 방법론 페이지로 링크 — **권장**: 근거를 보여주는 쪽이 신뢰도(E-E-A-T)에도 유리

**T2-2. 브리핑 상단에 AI 생성 고지 + 방법론 링크**
"이 브리핑은 실측 시장 데이터로 AI가 작성했으며 투자 권유가 아닙니다" + 방법론 페이지 링크.
이미 `/about/`에 데이터 원칙이 있으므로 링크만 걸면 된다.

### Tier 3 — 콘텐츠 보강 (⚠️ 방식이 중요)

**T3-1. 방법론·지식 가이드 5~8편** (진단은 15~20편을 권했으나 아래 이유로 줄인다)

**절대 하지 말 것: AI로 가이드를 대량 생성하는 것.** 구글의 최신 스팸 정책이 금지하는
*scaled content abuse*가 정확히 그것이다. 애드센스를 통과하려고 그 행위를 하는 것은
자기모순이고, 적발 시 도메인 단위 제재로 브리핑 서비스 전체가 위험해진다.

대신 **이 서비스가 실제로 구현한 것**을 설명한다. 코드에 근거가 있으므로 1차 경험이고,
E-E-A-T의 Experience에 해당하는 진짜 오리지널 콘텐츠다.

| 후보 | 근거가 이미 있는 곳 |
| --- | --- |
| 공포·탐욕 지수와 VIX로 시장 심리 읽기 | `_modals.html` 두 모달, `fetch_data.get_fear_greed()` |
| 밤사이 미국장으로 코스피 방향 가늠하기 | `build_overnight_bridge()`, `leading_signal.py` |
| 커버드콜 ETF 분배율의 함정 — 총수익으로 봐야 하는 이유 | `build_income_etfs.py` |
| 외국인·기관 수급을 읽는 법 | `fetch_closing_kospi.py` 수급 로직 |
| 밸류에이션 시그널 산식 (업종 상대 PER) | `fetch_valuation.py` |
| 우리는 예측을 어떻게 채점하는가 (적중률 공개) | `check_accuracy.py`, 성적표 카드 |

**5~8편을 제대로 쓰는 게 15~20편을 얇게 쓰는 것보다 낫다.** 각 1,500자 내외, 사람이
쓰고 다듬는다. 사이트의 기존 모달 설명이 좋은 초안 씨앗이다.

### Tier 4 — 측정

**T4-1. 구글 서치콘솔 등록 후 2~3주 색인 추적.** 신청은 그 다음이다. 색인 상태를 모르는
채로 신청하면 거절 사유를 학습할 수 없다.

---

## 3. 실행 순서

1. **T1-1 + T1-2** (허브 아카이브 + sitemap) — 1회 작업, 효과 가장 큼
2. **T2-1 + T2-2** (YMYL 완화) — 코드 변경 작음
3. **T4-1** GSC 등록 → 색인 쌓이는 동안
4. **T3-1** 가이드 5~8편 (사람이 작성)
5. **T1-3** 섹터 본문 보강
6. 애드센스 신청 — 신청 기간에는 URL 구조·레이아웃 변경을 멈춘다

## 4. 승인 가능성에 대한 정직한 견해

진단의 "10~20%"는 브리핑 본문(4,600자 × 79편)을 못 본 상태의 추정으로 보인다.
**T1만 끝내도 체감 확률은 크게 오른다** — 매일 실측 데이터로 만드는 오리지널 콘텐츠가
이미 79편 있고, 법적 고지·소개 페이지도 갖춰져 있기 때문이다.

다만 **YMYL(T2)은 콘텐츠 양으로 상쇄되지 않는다.** 진입/목표/손절 표기는 심사관 재량에
걸리는 항목이라, 여기를 손보지 않으면 양을 늘려도 정책 위반으로 거절될 수 있다.
