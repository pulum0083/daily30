# 브리핑 콘텐츠 보강 — 계획 (2026-10-26)

콘텐츠 점검(코스피·미국 10/23 렌더) 뒤 사용자가 고른 항목.

1. **미국 카드 제목 ↔ 실측 맞추기(점검 2)** — 코스피 '간밤 미국 · 실측' 카드가 종목 없는 이슈를 S&P500 하나로만 쟀다
   (제목 "S&P·다우 선물 동반 약세, VIX는 급등"). 제목에 나온 지수(S&P·다우·나스닥·VIX·러셀)를 프록시로 함께 잰다(`score_us_issues`).
2. **예측 근거 한 줄(코스피 요약 카드)** — prior 신호(SOX·나스닥·NQ선물·EWY 잔차·VIX) 실측을 한 줄로. 렌더 시 `leading_signal.compute_prior(market_data)`로 계산해 analysis에 넣어 스냅샷에 남긴다.
3. **전일 수급 한 줄(코스피 이슈 점검)** — `investor_trading`(정규장 15:31~15:40 확정, §51·§56)을 '국내 · 실측' 카드로. 순서 개인→기관→외국인(§10).
4. **프리마켓 실측 띠(미국 맨 위)** — ES·NQ·YM 선물 + 빅테크 6종 실체결가 등락. 발행 시점 데이터(§0 ①·§26). analysis에 넣어 스냅샷에 남긴다.
5. **미국 '상승 모멘텀 종목' → 월봉 5개월선 안착 코너** — 코스피(§61)와 같은 판정(`monthly_ma5.screen_one`)·화면. 유니버스는 미국 후보 목록(`US_CANDIDATES`). 미국용 백테스트 파일을 새로 만든다. LLM 픽(진입·목표·손절)은 화면·프롬프트에서 뺀다.
6. **메모리 현물가(보류)** — DRAMeXchange 공개 표가 매일 갱신되지만 재게시 허용 여부를 약관으로 확인한 뒤 정한다.
