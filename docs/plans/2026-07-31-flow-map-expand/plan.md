# 자금 지도 확장 패널 강화 (C-2 · 세로 그룹)

## 배경

`/stocks` 「이번 주 자금 지도」 타일을 클릭하면 확장 패널이 열리는데, 지금은 상위 ETF 5개의
**이름 + 금액** 두 줄이 전부다. 테마가 얼마나 집중돼 있는지, 5거래일 중 언제 들어왔는지,
테마 안에서 방향이 갈렸는지는 전혀 알 수 없다.

사용자 요청(2026-07-31): "하나 박스 클릭했을 때 나오는 정보가 더 풍부할 순 없을까."

## 무엇을 만드나

확장 패널을 세 블록으로 재구성한다.

```
① 일별 흐름 막대   최근 5거래일, 0축 기준(유입 위 / 유출 아래)
② 집중도          상위 5개가 테마 '움직인 자금'의 몇 % + 게이지 + 내부이동 배수
③ 유입/유출 그룹   방향별 세로 그룹, 각 그룹 전체 폭 + 소계
```

목업: [docs/prototypes/2026-07-31-flow-map-expand.html](../../prototypes/2026-07-31-flow-map-expand.html)
(실데이터 2026-07-31, 로컬 `http://localhost:8789/2026-07-31-flow-map-expand.html`)

## 왜 이 구성인가 — 실데이터로 확인한 근거

- **① 일별 막대**: 「미국 나스닥·기술 +1.2조」는 꾸준한 유입처럼 보이지만, 실제로는
  **7/28 하루에 1조가 빠져나갔다가** 이틀에 걸쳐 되돌아온 흐름이다. 누적 한 숫자가
  정반대 인상을 준다.
- **③ 방향 분리**: 16개 테마 중 **11개가 방향 혼재**다. 반도체는 순증 +2,129억인데
  오간 돈이 5,341억(2.5배) — 사실상 내부 이동이다.
- **세로 그룹(C-2)을 택한 이유**: 2단 분할(C-1)은 모바일 폭에서 종목명이 잘려
  `KODEX AI반도체TOP2플러스 +520억` 과 `SOL AI반도체TOP2플러스 −843억`이 둘 다
  "AI반도…"로 표시된다. 같은 지수를 추종하는 경쟁 ETF 사이의 자금 이동이라는
  가장 흥미로운 사실이 레이아웃 때문에 가려졌다.

## 설계 결정 3건 (목업 과정에서 발견)

### 1. 일별 금액은 **최종 NAV 기준**으로 계산한다

각 날의 NAV로 계산하면 일별 합이 헤더 누적과 어긋난다 — 반도체 실측 **1,748 vs 2,129 (−17.9%)**.
사용자가 막대를 더하면 헤더와 다른 숫자가 나온다. 한 화면 안에서 숫자가 서로를 부정하는 것은
이 서비스에서 결함으로 취급한다(SERVICE_RULES §28·§30).

최종 NAV로 통일하면 `Σ(shares[d]−shares[d−1])×nav_final = (shares[last]−shares[first])×nav_final`
로 **정확히 telescoping** 되어 누적과 일치한다. 정의도 일관된다 — "좌수 변화를 현재 가치로 환산".

중간 스냅샷에 없는 종목은 **직전 좌수를 carry-forward** 한다(= 그날 변화 없음). 이래야 종목 집합이
누적과 같아지고 telescoping이 깨지지 않는다.

### 2. 집중도 분모는 net이 아니라 **gross**(|흐름| 총합)

net으로 나누면 방향 혼재 테마에서 **130%** 같은 불가능한 값이 나온다(반도체 실측).
gross 기준이면 항상 0~100%이고, `gross / |net|` 배수로 "내부 이동이 얼마나 큰지"까지 표현된다.

### 3. ETF 브랜드 접두어를 **떼지 않는다**

`KODEX`/`TIGER`/`SOL`을 떼면 `AI반도체TOP2플러스`처럼 서로 다른 운용사의 동일 상품명이 충돌한다.

## 하위호환 (중요)

`daily`/`gross`는 다음 빌더 실행(평일 20:10 KST) 전까지 배포된 JSON에 없다.
**필드가 없으면 그 블록만 생략**하고 지금 화면 그대로 degrade한다 — 0으로 채우거나
추정하지 않는다(운영규칙 0 — 없으면 비운다).

## 성공 기준

1. `python3 scripts/test_build_etf_flows.py` 통과 — 특히 **일별 합 == 누적**.
2. 집중도가 어떤 테마에서도 100%를 넘지 않는다.
3. 브라우저에서 혼재 테마(반도체) 확장 시 종목명이 잘리지 않는다.
4. `daily`/`gross` 없는 구버전 JSON으로도 패널이 깨지지 않는다.
5. `node --test web/assets/*.test.mjs` · ESLint 0 errors 유지.
