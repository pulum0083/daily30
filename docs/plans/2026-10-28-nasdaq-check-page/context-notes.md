# 결정 노트
- 경로는 `/stocks/nasdaq-check/` — 종목 홈(/stocks/) 아래 신호 페이지. vercel 301 규칙(`/stocks/(\d{6}|us)`)에 걸리지 않는다.
- 페이지 원천은 그날 수집 파일. 날짜가 다르면 만들지 않는다(옛 페이지가 남는다 — §14 날짜 대조).
- 프로토타입 피드백(같은 날): 그래프 위 한 줄 값 표시 → 그래프 안 말풍선으로. 뒤로 가기는 섹터 페이지 버튼 모양으로 통일.
- 기준선 글자: 65·70이 겹쳐 65는 선 아래, 70은 선 위. 오른쪽 끝은 지금 점과 겹쳐 왼쪽에 둔다.
- 종목 홈: "상세 그래프 ›" 표시(처음 "1990년부터 그래프 보기 ›"는 좁은 화면에서 두 줄로 꺾였다), 섹터 막대 이름에 마우스 오버 색, '오늘 미국 브리핑' 라벨 제거.
- 휴대폰 탭은 클릭 도구가 마우스로 처리돼 화면으로 못 봤고, 터치 입력을 직접 보내 말풍선이 화면 안에 뜨는 것을 확인했다.
