# 나스닥 체크 상세 페이지 — /stocks/nasdaq-check/

## 무엇을
종목 홈 '구조 신호'의 나스닥 체크 줄을 누르면 상세 페이지로 간다(지금은 그날 미국 브리핑으로 간다).
브리핑의 나스닥 체크 섹션은 65% 미만이면 숨겨져(§65) 정상 구간엔 그래프를 볼 곳이 없었다.

## 사용자 결정 (2026-10-28)
- 기간: 1990년부터 — 닷컴 버블(1997~2000)·2020~2021 과열 구간이 보이게
- 그래프 두 개: ① 월별 이격률(65·70% 기준선) ② 나스닥 월봉 고점과 60개월선. 둘 다 짚으면 그 달 값이 뜬다
- 아래에 과거 통계·계산 방법

## 어떻게
1. `nasdaq_overheat.py` — 기존 `series`(2014~)는 그대로 두고 `history`(1990~, 월·이격률·고점·종가·60개월선)를 더한다
2. `generate_html.write_nasdaq_page(date)` — 그날 수집 파일(`data/nasdaq_overheat.json`, 날짜 같을 때만)로 정적 페이지를 만든다.
   그래프 SVG는 파이썬이 그리고, 짚었을 때 값은 페이지에 넣은 월별 숫자로 작은 스크립트가 띄운다
   (스크립트가 없어도 그래프는 보인다). 지수 그래프는 로그 눈금(1990년 ~400 → 2026년 ~27,000).
3. 미국 브리핑 렌더 때 함께 만든다(us 잡 `git add web/`가 커밋한다). 수동 `--nasdaq-page --date`.
4. `history`는 스냅샷에 넣지 않는다(브리핑마다 수십 KB가 쌓인다).
5. 종목 홈 줄 링크·브리핑 섹션 '자세히 보기' 링크·sitemap.

## 하지 않는 것
- 다른 구조 신호(월봉 5개월선) 상세 페이지 — 요청 범위 밖
