# 장중 '어제랑 비교' 가독성 개편

## 왜
- 곡선의 파란 면이 '어제보다 덜 올랐다'를 뜻했는데, 내내 오른 날(10/28, +1.97% → +6.53%)에도 처음 30분이 파랗게 보여 '빠졌다가 올랐다'로 읽혔다.
- 아래 카드(강도·주도권·수급)가 어제·오늘 짝 막대 칸을 늘어놓아 길고(모바일 427/1,226/840px) 무엇을 봐야 하는지 흐렸다.

## 무엇을
사용자가 시안에서 고른 조합(`docs/prototypes/2026-10-28-vs-intraday-final.html`)을 운영 화면(`web/assets/vs-yesterday.js`·`.css`)에 반영한다.
1. 결론 곡선 — 시안 B: 맨 위 세 칸(오늘·어제 같은 시각·차이), 면은 오늘 곡선과 0%선 사이(0% 위 빨강·아래 파랑), 차이 막대는 회색.
2. 얼마나 뜨거운가 — 숫자 두 개(거래량 %, 진폭 배수) + 판정 뱃지.
3. 어디가 이끄나 — 시장 기준선(섹터 막대 + 코스피·코스닥 점선, 순위 칸·이동 화살표).
4. 누가 사는가 — 판 쪽 vs 산 쪽 막대(오늘·어제 이 시각) + 기관 순매수 구성.

서버(`api/_vs-*.mjs`) 응답은 그대로 쓴다. 새 데이터를 만들지 않는다.
