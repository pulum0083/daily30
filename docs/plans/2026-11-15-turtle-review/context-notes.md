# 터틀(리처드 데니스) 규칙 — 브리핑 섹션 가능성 점검 (2026-11-15)

계기: 사용자가 손절봇 터틀 요약 PDF를 주고 브리핑 섹션으로 만들 수 있는지 물었다.
규칙: 20일 최고가 돌파(직전 신호가 이겼으면 건너뜀)·55일 최고가는 무조건 / N = 20일 하루 평균 움직임 /
손절 = 산 가격 − 2N, ½N마다 한 단위 더(최대 4) / 10일(55일 진입은 20일) 최저가를 깨면 전부 판다.
전부 일봉으로 정해져 쿨라매기와 달리 일봉 시험이 실제 규칙과 거의 같다(산 날엔 추가 매수 안 함, 산 날 2N 아래면 손절로 처리).

- 55/20 보유 중앙값 12거래일, 한 시장에 1년 약 3번 신호.

## 제안
종목 고르기가 아니라 '시장 추세판'으로만 쓴다(한국·반도체·나스닥·금·원유·장기채·달러·엔 등).
매수 쪽 상태만 보여준다(55일 최고가 돌파 뒤 20일 최저가를 안 깬 시장 = 상승 추세 중, 며칠째, 청산선까지 거리).
숏 성적이 마이너스라 '하락 추세 = 팔아라'로 쓰지 않는다. 성적은 무작위 기준과 함께 밝힌다.
