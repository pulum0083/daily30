# 코스피 아침 브리핑 3단 구조 — 결정 노트

## 2026-10-26 (구현 시작)

### 섹션 공유 여부 (빼기 전에 확인)
- 마감(`close.html`)과 같이 쓰는 것: `scenario_split`·`qa`·`signal_board`·`_comfort_line`. 템플릿은 그대로 둔다(코스피 include만 뺀다). 이 셋은 `format_in_view`가 없을 때 제목 아래 `close_dek`를 그린다 — 마감은 그 값을 넘기지 않으므로 영향 없음.
- 미국(`us.html`)은 위 목록 중 어느 것도 쓰지 않는다(오늘의 관점은 템플릿 안 인라인, `_issues.html` 별도).
- 코스피만 쓰던 것: `todays_view`·`prediction`·`prediction_strip`·`us_issue_results`·`domestic_issues`·`ib_korea_views`·`why_what_so`·`flow_chain`·`key_numbers`. `reasons`·`watchpoints`는 이미 어디서도 include되지 않는다.
- `scripts/config/*.json`의 `sections_main`은 렌더에 쓰이지 않는다(템플릿이 include를 직접 정한다). 테스트 하나가 목록을 검사해서 값만 맞춰 둔다.

### 사용자 결정
- 이슈 카드의 '코스피 ▼ AI 판단' 칩은 뺀다 — 프로토타입에서 세 장 모두 ▼로 하드코딩돼 있었고 스냅샷에 근거 값이 없다.
- 국내 종목 링크는 키워드 규칙으로 유지(반도체·메모리 → 삼성전자·SK하이닉스). 'AI 해석'이 아니라 '관련 종목'으로 표기하고 상세 페이지가 있을 때만 링크(§36).
- 외국계 시각은 이슈 점검 안 '외국계 · 뉴스' 카드로 옮긴다.
- 성적표: 계산은 맞고 라벨이 틀렸다(시초가 채점 9건인데 `scored[-15:]`가 9건 전부 → '최근 15건 78%' = '누적 9건 78%'). 15건이 되기 전엔 '최근 15건'을 숨긴다.

### 구현 중 발견
- 프로토타입 머리의 '06:35 생성'은 하드코딩이다. 10/23 발행본은 07:26(시장 데이터 생성 시각) — 옛 예측 스트립과 같은 `generated_time`을 쓴다.
- 어제 예측 칩: 화~금 07:25엔 전날 예측이 아직 채점 전이다(정확도 체크가 09:10). 프로토타입은 채점이 끝난 뒤의 `briefings.json`으로 만들어서 보였다. 채점 기록이 없으면 전날 시초가 갭을 네이버 지수 일봉으로 직접 구해 채점한다(`check_accuracy.get_kospi_open_gap`, 마감 배지와 같은 방식). 그것도 못 구하면 칩을 뺀다(§16 — 더 오래된 결과로 대신하지 않는다). 결과는 `analysis["prev_prediction_result"]`에 넣어 스냅샷에 함께 저장한다 — 재생성해도 바뀌지 않게.
- `domestic_issues`·`ib_korea_views`는 스냅샷이 아니라 `data/*.json`에서 읽는다. 비교 렌더는 git 이력(`b621326d` = 10/23 발행 커밋)의 두 파일을 임시로 써서 만든다.
- `build_ib_korea_views()`에는 날짜 검사가 없다(국내 이슈엔 있다). 이번 범위 밖 — 남은 갭으로 적어 둔다.
