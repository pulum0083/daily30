# 코스피 아침 브리핑 3단 구조 — 실제 템플릿 적용 계획

프로토타입: `docs/prototypes/2026-10-25-kospi-briefing-3tier.html` (10/23 발행본 기반, 스타일은 운영 사이트에서 불러온다 — 브라우저로 그대로 열면 된다).
프로토타입 빌더(참고용): `build_3tier_proto.py` — 로컬 전용 미리보기(`web/_proto/ma5final`)를 입력으로 써서 다른 컴퓨터에서는 그대로 돌지 않는다. 데이터 매핑을 읽는 용도로만 쓴다.

## 목표
코스피 아침 브리핑 첫 화면에서 예측을 바로 보게 하고, 본문 중심을 "오늘의 이슈 점검"으로 옮긴다.
모바일 기준 예측 위치 1,763px → 108px, 이슈 점검 1,169px → 428px, 페이지 높이 4,730 → 약 3,900px(프로토타입 실측).

## 확정된 구조 (사용자 결정 2026-10-25)
1. **30초 요약 카드(`.bx-hero`)**
   - 머리: `10월 23일(금) 시초가 방향 예측` · `06:35 생성`
   - 방향(`↓ 하락 우위`)과 확률(`93%`)을 한 줄, **같은 기준선·같은 크기(30px)**. 확률 아래 `신뢰도 82%`.
   - 헤드라인 `todays_view.view_title` (재미있는 헤드라인 규칙 §62)
   - **보조 문장 `todays_view.dek`** — 헤드라인 바로 아래, 1문장 최대 3문장(프롬프트 반영 완료)
   - 칩: **어제 예측 결과만** (`어제 예측 상승 → 빗나감 · 시초가 -1.14%`). **적중률 칩은 넣지 않는다.**
   - 정의 한 줄: "09:00 코스피가 전일 종가보다 위로 열릴지 아래로 열릴지에 대한 확률이에요. 장중 흐름과 종가는 예측하지 않아요."
   - **위로 한 줄(comfort_line)은 넣지 않는다.**
2. **오늘의 이슈 점검(`.ic-section`)** — 본문 메인
   - 간밤 미국 · 실측 카드: `us_issue_results.cards` 그대로(숫자는 여기서 한 번만), 반도체 카드엔 국내 연결(삼성전자·SK하이닉스, "AI 해석" 표기)
   - 국내 · 뉴스 카드: 기존 `domestic_issues` 수집분(출처·링크 그대로)
   - 오늘 볼 것 · AI 해석 카드: `todays_view.outlook`
   - 태그 3종(실측/뉴스/AI 해석) + 하단 범례 문장 + "간밤 미국 브리핑 보기 →"
   - 카드의 "코스피 ▼ AI 판단" 칩과 국내 종목 링크는 유지 여부 미정 — 적용 전에 사용자에게 확인
3. **월봉 5개월선 안착 종목(§61)** — 독립 섹션, 지금 그대로. 섹션 아래 여백 28px(모바일에서 바로 아래 시장 지표 카드와 붙지 않게)
4. **근거 전체 보기(key_drivers·WHY·WHAT·SO WHAT)는 넣지 않는다.** 사이드바는 그대로.

## 적용 시 주의
- 수정 대상: `scripts/templates/briefings/kospi.html`, `scripts/config/kospi.json`의 `sections_main`, 새 섹션 템플릿(요약 카드·이슈 점검), `web/assets/style.css`(프로토타입 `#tier3-css`·인라인 스타일을 옮기고 `ASSET_VER` 갱신).
- 지금 `todays_view.html`·`prediction.html`·`reasons.html`·`watchpoints.html` 등이 그리는 내용이 요약 카드·이슈 점검과 겹친다 — 빠지는 섹션을 정리하되 **미국·마감 브리핑이 같은 섹션을 쓰는지 먼저 확인**한다.
- **발행된 브리핑은 재생성하지 않는다(§33).** 새 템플릿은 다음 발행부터. 확인은 커밋 안 하는 경로(`render_briefing`로 10/23 스냅샷 렌더)로 한다.
- 브리핑 잡 시간(07:25~07:45 · 16:25~16:50 · 21:15~21:40 KST)에는 생성물을 푸시하지 않는다(§43).
- 텔레그램은 정해진 시각에만 나간다. 테스트 발송 금지.
