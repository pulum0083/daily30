SECTION 1

전반 경쟁력 — 있는가?

결론부터: 잠재 경쟁력은 있으나, 현재의 간판(예측)으로는 못 이긴다.

경쟁 지형에서의 위치

영역대표 주자그들의 무기더블샷의 상대 우위
시세·데이터네이버 금융, 토스증권완전한 데이터, 압도적 트래픽없음 — 정면 승부 불가 영역
아침 브리핑순살브리핑, 어피티 등 뉴스레터필진 브랜드, 구독자 규모정량 예측 + 성적 공개 (그들은 절대 안 함)
투자 도구ETFNow 등수천 페이지 롱테일 SEO실측 파이프라인 재사용 시 더 깊은 페이지 가능
AI 분석다수 신규 진입자화려한 UI, 마케팅94일 누적 트랙레코드 — 시간이 만든 해자

냉정한 현실 세 가지

① 예측은 더 이상 세일즈 포인트가 아니다. 전체 64%는 동전보다 유의미하게 높지만, 최근 15건 47%는 사용자가 체감하는 "요즘 성적"이다. 예측을 전면에 세울수록 매일 심판받고, 최근 성적표로는 심판에서 진다. 반면 미국 브리핑 71%는 상대적으로 건재 — 자산과 부채가 갈리고 있다.

② 유입 구조가 닫혀 있다. 텔레그램·이메일 푸시 루프는 기존 구독자를 유지할 뿐 새 사용자를 데려오지 못한다. 일 방문 40~50명 감소 추세(6/16 보고 기준)가 그 증거다. 색인 페이지 94개는 시작이지만, ETFNow류 서비스의 수천 페이지 대비 임계질량 미달이다.

③ 그러나 원가 구조가 남다르다. 이 서비스의 진짜 경쟁력은 예측 정확도가 아니라 "사람 손 없이 매일 실측 데이터 기반 콘텐츠를 찍어내는 공장"이다. 콘텐츠 생산 한계비용이 0에 가까우므로, 페이지를 46개에서 200개로 늘리는 데 드는 비용이 경쟁자 대비 압도적으로 낮다. 이 공장을 어디에 돌리느냐가 전부다.

포지셔닝 재정의 제안 — "오를지 내릴지 맞히는 서비스"가 아니라 "매일 아침 3분, 오늘 시장의 인과를 정리해주고 자기 성적을 숨기지 않는 서비스". 예측은 여러 코너 중 하나로 내리고, 정직한 트랙레코드를 브랜드 그 자체로 올린다.
SECTION 2

3개 메뉴 구조 — 적절한가?

구조는 적절하다. 문제는 개수가 아니라 연결이다.

메뉴퍼널에서의 역할측정할 핵심 지표현재 상태
브리핑습관 — 매일 돌아오게 하는 심장박동재방문율 · 푸시 클릭률예측 의존 과다
종목 시그널유입 — 검색으로 들어오는 문검색 유입 수 · 색인 페이지 수커버리지 부족
월배당심화 — 체류·공유·차별화 도구체류 시간 · 공유 수단일 페이지

유입(검색) → 습관(브리핑) → 심화(도구)라는 역할 분담은 교과서적으로 옳고, 1인 운영 리소스에서 메뉴를 늘리는 것은 금물이다. 3개 유지가 정답이다.

진짜 문제는 저장소 전수 조사에서 나왔다. 브리핑 → 종목 페이지 링크 2개, 종목 페이지 → 브리핑 링크 0개. 매일 브리핑이 삼성전자를 언급하는데 그 자리에서 삼성전자 영구 페이지로 이어지지 않고, 종목 페이지에 온 검색 방문자는 "이 서비스가 매일 아침 브리핑도 한다"는 사실을 알 방법이 없다. 세 메뉴가 각자 잘하는 걸 서로에게 넘겨주지 못하는 구조 — 퍼널이 아니라 세 개의 섬이다. 연결 배선은 템플릿 수정만으로 가능해 비용 대비 효과가 가장 크다.

SECTION 3

메뉴별 보강 포인트

각 메뉴의 역할에 맞춰 — 습관은 심판받지 않게, 유입은 임계질량을, 도구는 반복 사용을.

브리핑역할: 습관 · 심장박동
현재하루 3건 + 이슈 22회 무인 발행. 라이브 스코어보드·포맷 로테이션(오늘 flow·keynum 추가로 6종) 등 읽는 재미 장치는 갖춰짐. 단 아침 브리핑이 예측 적중 여부에 매일 노출되는 구조.
보강
  • 무게중심을 "심판받지 않는 콘텐츠"로 — 마감 브리핑(예측 없음)과 이슈 브리핑은 틀릴 수가 없다. 아침 브리핑도 "방향 맞히기"보다 "오늘 뭘 봐야 하는가" 큐레이션 비중을 키운다. 포맷 다양화는 정확히 이 방향.
  • 성적표를 숨기지 말고 무기로 — "우리 성적표" 상설 페이지(월별 적중률·최근 추세·틀린 날 복기)를 만들어 전면 배치. 47%든 71%든 그대로 공개하는 서비스는 없다. 정직함 자체가 차별화다.
  • 푸시 제목에 가변 보상 심기 — "어제 예측 ○/× + 오늘의 한 줄"을 제목에 넣으면 결과 확인 심리로 열게 된다.
  • 브리핑 본문의 모든 종목명을 영구 페이지로 링크 — 매일 자동으로 내부 링크가 쌓이는 SEO 배선이기도 하다.
종목 시그널역할: 유입 · 검색의 문
현재KR 46 + US 8 + 섹터 8 페이지. 오늘의 시그널·수급·외국인 보유율·분기 실적·픽 트랙레코드까지 페이지 깊이는 이미 경쟁작 수준. 문제는 폭 — 코스피200 대비 23% 커버리지로는 롱테일 검색을 못 받는다.
보강
  • 커버리지 46 → 코스피200 — 생산 한계비용이 0에 가까운 이 서비스의 최대 레버. "○○전자 주가 전망" 롱테일 하나하나가 문이다.
  • "어제와 달라진 것" 델타 표시 — 시그널 전환·수급 방향 전환·외국인 보유율 변화를 페이지 상단에 배지로. 매일 갱신되는 게 보여야 재방문한다.
  • 픽 트랙레코드를 상단으로 — "이 종목을 더블샷이 N번 픽했고 성적은 이랬다"는 유일무이한 콘텐츠. 검색 방문자의 체류를 만든다.
  • Search Console 색인 실태 점검 — 94개 URL 중 실제 색인·노출·클릭을 확인해야 커버리지 확대의 효과를 측정할 수 있다.
월배당역할: 심화 · 도구
현재계산기 + 진단 리포트 단일 페이지. 도구 완성도는 있으나 한 번 쓰고 떠나는 구조 — 결과 저장·공유·재방문 장치가 없다.
보강
  • 결과 공유 URL — 진단 리포트를 URL 파라미터로 재현 가능하게. 커뮤니티·단톡방에 퍼지는 유일한 경로가 공유 링크다.
  • "내 월배당 플랜" 저장 — localStorage만으로 시작. 저장한 플랜이 있으면 재방문 이유가 생긴다.
  • ETF별 영구 페이지 + 분배금 캘린더 — "○○ETF 분배금 지급일" 검색 수요는 매월 반복된다. 월간 회귀 트리거이자 SEO 자산.
SECTION 4

매일 쓰게 만드는 트리거

습관 = 계기 → 행동 → 가변 보상 → 사용자가 쌓는 것. 지금 더블샷은 계기만 있고 마지막 고리가 없다.

핵심 공백: 사용자가 쌓는 것이 없다

지금 사용자가 더블샷에 남겨둔 것은 이메일 주소 하나뿐이다. 관심종목도, 저장된 플랜도, 설정도 없다. 떠나는 데 아무 비용이 들지 않는다. 워치리스트(localStorage, 로그인 불필요)가 첫 단추다 — 종목 페이지에 ☆ 버튼 하나, 종목 허브 상단에 "내 종목" 줄 하나. 내 종목이 등록되는 순간 "오늘 내 종목 시그널 어때?"라는 개인화된 방문 이유가 생기고, 이것이 위 표의 모든 시간 트리거를 "남의 브리핑"에서 "내 것 확인"으로 바꾼다.

참고: 발송 시각은 한국 개미의 실제 루틴(08:50 장전 · 15:40 마감 직후 · 22:30 미장 개장)과의 정렬을 점검해볼 가치가 있다. 습관은 기존 루틴에 얹힐 때 가장 싸게 만들어진다.
