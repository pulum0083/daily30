STRATEGY REPORT

더블샷, "읽고 끝나는 브리핑"에서
"하루 종일 켜두는 시장 도구"로

사용자 이탈 진단 · 경쟁 서비스 분석 · 종목 시그널 정밀 분석 · 개편 로드맵 — 2026-07-17 · doubleshot.space (v2)

요약 (TL;DR)

  1. 사용자가 떨어지는 근본 원인은 콘텐츠 품질이 아니라 구조다. 더블샷은 하루 3번 "읽고 끝나는" 서비스이고, 벤치마크 두 곳은 하루 수십 번 "돌아오게 만드는" 도구다.
  2. 사이트에 사용자의 것이 하나도 없다. 관심종목도, 기록도, 참여도 없다. 다시 올 이유가 콘텐츠 갱신뿐이면 재방문은 발행 횟수(3회)가 상한이 된다.
  3. 종목 시그널은 "절반쯤 완성된 도구"다. 데이터 깊이(목표주가 컨센서스·수급·분기실적·종목별 픽 채점)는 경쟁사를 이미 앞서는데, 종가 기준 정적 화면 + 개인화 부재 + 40종목 커버리지 + 브리핑과의 단절 때문에 습관이 되지 못하고 있다. 개편의 중심 무대는 여기다.
  4. 반격 카드는 이미 손에 있다. ① 채점되는 예측(적중률 67%·확정 125건)은 두 경쟁사 모두 없는 유일 자산이고, ② HL 24h 환산 시세는 코스피랩의 핵심 훅과 같은 데이터인데 이미 수집 중이며, ③ 종목 상세 페이지의 데이터 위계는 코스피랩 리포트 섹션의 상위 호환이다. 문제는 이것들이 화면 구석에 묻혀 있거나 서로 연결돼 있지 않다는 것.
  5. 권고: P0 = 관심종목(로그인 없이) + 24시간 시세 홈 전면화, P1 = 예측 트랙레코드 전면화 + "나도 예측" 투표·스트릭, P2 = 종목 커버리지 확대 + 텔레그램 유입 구조 개선. 커뮤니티·모의투자 같은 무거운 기능은 지금 단계에선 비권장.

1.진단 — 왜 사용자가 떨어지는가

문제는 "무엇을 보여주느냐"가 아니라 "언제 다시 오게 하느냐"다.

더블샷의 현재 사용자 여정을 그대로 옮기면 이렇다.

텔레그램 알림 도착 (07:30 / 16:30 / 21:20) → 텔레그램 안에서 요약을 읽음 → 대부분 여기서 종료 (텔레그램만으로 충분히 소비됨) → 일부만 상세 페이지 클릭 → 읽고 닫음. 저장할 것도, 남길 것도, 내일 확인할 것도 없음

이 구조에는 세 가지 상한이 있다.

  • 방문 횟수의 상한 — 발행 스케줄. 콘텐츠가 하루 3번 나오면 방문 동기도 하루 3번이 최대다. 반면 시세·랭킹 같은 "상태"는 볼 때마다 다르므로 방문 횟수에 상한이 없다.
  • 텔레그램이 목적지가 되어버림. 브리핑의 핵심(방향·확률·근거)이 텔레그램 메시지 안에서 완결되므로, 사이트는 "더 긴 버전"일 뿐이다. 채널 구독자 수와 사이트 사용자 수가 따로 노는 이유다.
  • 축적되는 것이 없음. 사용자가 서비스에 시간을 쓸수록 쌓이는 자산(내 종목 리스트, 내 예측 기록, 내 수익률)이 없으면 이탈 비용이 0이다. 떠나도 잃는 게 없다.

종목 시그널 페이지는 데이터 품질(전 수치 실측, 출처 명시)이 강점이지만, 지금은 "모두에게 같은 화면"이다. 내 종목이 8개 섹터 40여 종목 안에 없으면 그날로 이탈한다. 개인화 없는 대시보드는 첫 방문 감탄은 만들어도 재방문 습관은 만들지 못한다. 종목 시그널이 가진 자산과 한계는 §3에서 따로 뜯어본다.

3.종목 시그널 정밀 분석 — 이미 절반쯤 만들어진 도구

허브(/stocks)와 상세(/stocks/{code}/)를 2026-07-17 기준으로 실사용 점검했다.

이미 갖춘 것 — 데이터 위계는 경쟁사보다 깊다

허브 페이지는 시간대 인지형 헤더(장중/마감), 주도주 3종목의 HL 24h 환산 + 실측 1분봉 + 뉴스 핀, 거래량 배수·레인지 위치·VWAP, 밤사이 미국 반도체 시황(원화 환산), 섹터 8개 대표 종목, 밸류에이션 시그널(업종 대비 선행 PER), 특이 신호(역행 상승·신고가 근접·수급 전환 교차 규칙), ETF로 읽는 시황(인버스/레버리지 거래대금 비율)까지 담고 있다. 상세 페이지는 종목당 이렇게 쌓여 있다.

특히 종목별 픽 트랙레코드는 주목할 만하다. "7/15 픽 → 목표 도달 +5.5%, 7/7 픽 → 미도달 -20.3%"를 실측으로, 실패까지 그대로 보여준다. 브리핑(예측)과 종목 페이지(도구)를 잇는 유일한 다리이자, 서비스 전체의 신뢰 서사("우리는 채점받는다")를 종목 단위로 증명하는 장치다. 지금은 페이지 하단에 조용히 놓여 있다.

그런데 왜 리텐션으로 이어지지 않는가

  • 본질이 "일일 리포트"다. 시세·수급·시그널이 전부 직전 거래일 종가 기준으로 하루 1번 갱신된다(장중 실시간은 주도주·시그널 일부뿐). 하루 1번 보면 더 볼 게 없으니 방문 상한도 하루 1번 — 브리핑과 같은 구조적 한계를 반복하고 있다. 경쟁사 둘은 같은 화면이 10초~수분마다 달라진다.
  • 모두에게 같은 화면. 관심종목이 없으니 사용자는 매번 8개 섹터를 스크롤해서 자기 종목을 찾아야 하고, 유니버스 밖 종목이면 그마저 없다. 데이터가 깊을수록 "내 종목만 모아 보고 싶다"는 욕구는 더 커진다.
  • 커버리지 40여 종목. 상세 페이지 품질은 높은데 존재하는 페이지가 적어, 검색 유입도 재방문도 그 수에 갇힌다. 품질×수량 중 수량이 병목이다.
  • 브리핑과의 동선이 끊겨 있다. 아침 브리핑의 종목 픽에서 해당 종목 상세 페이지로, 종목 페이지에서 오늘 브리핑으로 오가는 흐름이 약하다. 픽 트랙레코드라는 다리를 이미 만들어 놓고 양쪽에서 안내하지 않는 셈이다.
  • 발견성. "종목 시그널"이라는 이름만으로는 목표주가·수급·실적까지 있다는 걸 알 수 없고, 랜딩 페이지에서도 이 페이지의 존재감이 작다(footer급 "인컴 디자이너" 링크 수준). 가장 잘 만든 자산이 가장 덜 알려져 있다.

정리하면 종목 시그널은 "경쟁사보다 깊은 데이터를, 경쟁사보다 얕은 빈도로" 보여주고 있다. §5의 P0(관심종목·24h 전면화)가 다른 곳이 아니라 바로 이 페이지 위에서 실행돼야 하는 이유다 — 새 제품을 만드는 게 아니라, 이미 있는 도구에 "실시간"과 "내 것"을 얹는 일이다.

4.방향 — 포지셔닝 재정의

한 문장으로: "AI가 예측하고, 시장이 채점하고, 나는 하루 종일 확인한다."

브리핑을 버리자는 게 아니다. 브리핑을 "제품"에서 "제품 안의 콘텐츠"로 강등시키고, 제품 자체는 "24시간 살아있는 코스피 화면 + 내 종목 + 채점되는 예측"으로 재정의하자는 것이다.

개편 후 사용자 여정 (목표) 아침 텔레그램: "어제 예측 적중 ✓ (누적 67%) · 오늘은 하락 우위 65%" → 사이트에서 근거 확인 + 내 관심종목 오늘 신호 확인 장중 내 종목 실시간 + 주도주 곡선 + 이슈 브리핑 30분 갱신 → n회 재방문 저녁 마감 브리핑 + "오늘 내 예측은 맞았나" 채점 확인 밤 "지금 삼성전자 얼마?" — HL 24h 환산 시세 (검색 유입 + 재방문) 반복 내 관심종목·내 예측 스트릭이 쌓임 → 이탈 비용 발생

5.실행 제안 — 우선순위별

P0는 2주 내, P1은 4~6주 내, P2는 그 이후. 1인 운영·현재 파이프라인 재사용을 전제로 했다.
P0

관심종목 — 로그인 없이, localStorage로 시작

재방문을 만드는 최소 단위이자 가장 싼 개인화다. 종목 시그널 페이지에 ★ 버튼 하나 추가하고, 등록한 종목을 홈 최상단에 "내 종목" 스트립으로 고정한다. 이미 종목별 실측 데이터 파이프라인(토스·네이버)이 있으므로 새 데이터 수집이 필요 없다. localStorage면 계정·서버 비용도 0이다.

  • 내 종목에는 현재가·등락률에 더해 더블샷만의 레이어를 얹는다 — 특이 신호 발생 여부, 밸류에이션 시그널, 수급 전환. "네이버에도 있는 시세"가 아니라 "더블샷이라 보이는 신호"가 차별점.
  • 텔레그램 확장 훅: 내 종목에 특이 신호(52주 신고가 근접, 기관 순매수 전환 등)가 뜨면 알림 — 기존 신호 엔진(/api/signals) 재사용.
P0

24시간 시세를 구석에서 전면으로

코스피랩의 존재 이유인 "장 마감 후 추정가"를 더블샷은 이미 갖고 있다(주도주 위젯의 HL 24h 환산). 이걸 3종목 위젯에서 꺼내 독립 화면급으로 승격한다.

  • 종목 시그널 홈 히어로를 시간대 인지형으로: 장중엔 실시간 지수·주도주, 장 마감 후엔 "지금 이 시각 추정가" 모드로 자동 전환. 밤 시간대(미국장·해외 변수)가 오히려 개미들이 제일 궁금해하는 시간이다.
  • "밤사이 미국 반도체 시황" 섹션과 결합하면 "밤에 보는 코스피 화면"이라는 고유 슬롯을 가질 수 있다 — 국내 서비스 대부분이 비워두는 시간대다.
  • 검색 유입 노림수: "삼성전자 실시간", "코스피 야간 시세" 류 검색어에 대응하는 영구 URL. 기존 /stocks/{code}/ 페이지 전략과 합류.
P1

트랙레코드를 서비스의 얼굴로

"매일 예측하고 다음 날 시장이 채점한다"는 구조는 두 경쟁사 모두 없고, 개인 유튜버·리딩방과도 정반대(그들은 틀린 예측을 지운다)인 신뢰 자산이다. 지금은 랜딩 한 줄("누적 적중률 67%")에 묻혀 있다.

  • 전용 페이지 /track-record — 전 예측 이력을 날짜·방향·결과와 함께 전부 공개. 틀린 것도 그대로. 데이터는 data/briefings.json에 이미 다 있다 (프로토타입 docs/prototypes/track-record.html 존재 — 이걸 완성해 배포하는 것으로 충분).
  • 매 브리핑 상단에 "어제 예측 → 결과" 배지 상시 노출 (§16 방지 룰 준수 — 미채점이면 생략, 옛 결과 대체 금지).
  • 텔레그램 아침 메시지 첫 줄을 결과 보고로: "어제 하락 우위 예측 → 실제 -6.37% ✓ (누적 67%)". 공유하고 싶은 카드 이미지로도 제작.
  • 종목별 픽 트랙레코드를 다리로 쓴다. 이미 종목 상세 페이지에 픽 채점("7/15 픽 → 목표 도달 +5.5%")이 있으니, 브리핑의 종목 픽에는 상세 페이지 링크를, 종목 페이지 상단에는 "오늘 브리핑에서 이 종목 언급" 배지를 달아 브리핑↔종목 양방향 동선을 만든다. 새 데이터 없이 링크만으로 두 축이 연결된다.
P1

"나도 예측" — 커뮤니티 없이 참여를 만드는 최소 장치

엑셀코스피의 모의투자 리그를 그대로 만들기엔 무겁다. 같은 심리(경쟁·축적·매일 확인)를 훨씬 싸게 얻는 방법이 원탭 방향 투표다.

  • 아침 브리핑에서 "AI는 하락 우위 65%. 당신의 예측은?" — 상승/하락 버튼 하나. 다음 날 AI와 함께 채점.
  • 사용자에게 쌓이는 것: 내 적중률, 연속 적중 스트릭, "AI를 이긴 날" 카운트. localStorage로 시작 가능, 집계는 경량 API 하나면 된다.
  • 사회적 존재감은 접속자 수·투표 분포("오늘 참여자의 62%가 하락에 투표")로 대신한다 — 커뮤니티 콜드스타트 리스크 없이.
  • 이것이 자리 잡으면 자연스럽게 리그·랭킹(P3)으로 확장할 수 있다. 처음부터 리그를 만들지 않는다.
P1

텔레그램 메시지 구조 개편 — 완결형에서 유도형으로

지금의 텔레그램은 너무 친절해서 사이트에 올 이유를 없앤다. 메시지에서 다 주지 말고, 사이트에서만 볼 수 있는 것을 명시적으로 남긴다.

  • 텔레그램: 결과 배지 + 오늘 방향·확률 + 핵심 근거 1줄 + "나도 예측하기" 링크.
  • 사이트 전용: 근거 전체, 종목 픽, 내 종목 신호, 투표, 라이브 스코어보드. "실시간"과 "개인화"는 메신저로 배달할 수 없는 것들이라 자연스럽게 사이트 몫이 된다.
  • 주의: 정보를 인질로 잡는 느낌이 들면 역효과다. 텔레그램 단독으로도 유용하되, 사이트가 "더 살아있는" 구조로.
P2

커버리지 확대 — "내 종목이 없어서 나가는" 이탈 차단

  • 현재 8개 섹터 40여 종목 → 코스피200 + 코스닥150 단계 확대 (이미 페이지에 예고돼 있음). 관심종목 기능(P0)의 가치가 커버리지에 비례하므로 P0 이후 최우선.
  • /stocks/{code}/ 영구 페이지 확대는 기존 검색 유입 전략(ETFNow → 종목 엔진)과 동일 방향 — 별도 전략 수립 불요, 실행만 남음.
P2

PWA·홈 화면 설치

  • 두 경쟁사 모두 "앱 설치" 버튼이 있다. 매일 여는 서비스가 되려면 브라우저 북마크보다 홈 화면 아이콘이 유리하다. manifest + 서비스워커 수준의 경량 PWA로 충분.

하지 말 것 (지금은)

❌ 게시판형 커뮤니티

콜드스타트가 가장 어려운 기능. 빈 게시판은 오히려 "죽은 서비스" 신호가 된다. 투표·분포 표시로 참여감을 먼저 만들고, 임계 사용자 확보 후 검토.

❌ 위장 UI 콘셉트 추종

엑셀코스피의 위장은 그 서비스의 정체성이라 따라하면 아류가 된다. 더블샷의 정체성은 "검증된 예측"이다. 콘셉트가 아니라 구조(도구화)를 배울 것.

❌ 풀 모의투자 리그

체결 엔진·계정·리그 운영은 1인 운영 범위를 넘는다. "나도 예측" 투표가 같은 심리를 1/20 비용으로 검증해 준다.

❌ 브리핑 발행 횟수 늘리기

콘텐츠 추가는 상한이 발행 횟수인 구조를 강화할 뿐이다. 지금 필요한 건 발행 사이 시간을 채우는 "상태" 화면이다.

6.로드맵과 측정

기능보다 측정을 먼저. 지금은 "떨어진다"는 감각만 있고 어디서 새는지 수치가 없다.

북극성 지표는 "주 3일 이상 방문하는 사용자 수(WAU 중 습관 사용자)"를 권한다. 브리핑 서비스의 조회수가 아니라 도구의 습관성을 재는 지표이기 때문이다. 보조 지표는 관심종목 등록률, 투표 참여율, 텔레그램 클릭률, 장외 시간대(15:30~다음날 07:30) 방문 비중.

한 줄 결론 — 엑셀코스피는 "하루 종일 켜둘 이유"를, 코스피랩은 "밤에도 볼 이유"를 팔고 있다. 더블샷은 이미 그 재료(실측 파이프라인, HL 24h, 신호 엔진)를 다 갖고 있으면서 "하루 3번 읽을 이유"만 팔아 왔다. 자산을 재배치하면 된다. 새로 만들 것보다 꺼내서 전면에 놓을 것이 더 많다.
