# ETF 사이드바 블록 통합 설계

/ web/stocks/index.html 우측 사이드바 — "ETF로 읽는 시황" + "ETF 베팅 흐름"을 한 블록으로 합치고 거래량 톱5 ETF를 추가한다.

작성일: 2026-06-27

## 배경

현재 `web/stocks/index.html`의 우측 사이드바(`.home-side`)는 4개 블록으로 구성된다.

1. **ETF로 읽는 시황** (`#etf-lead`) — 헤드라인 제목 + 본문 (인버스 거래량 배수로 카피 생성, `etfLead(betting)`)
2. **ETF 베팅 흐름** (`#etf-betting`) — 하락베팅/저점매수 분할바 + 인버스 거래량 배수·레버리지 등락률 팩트 + 노트
3. **섹터 로테이션** (`#etf-sector`) — 섹터 top3/bottom3
4. **안전자산 선호도** (`#etf-safehaven`) — 안전자산 행 + 코스피200 + "ETF 전체 랭킹 →" 링크

①과 ②는 둘 다 ETF 자금 흐름을 읽는 위젯이라 내용이 겹친다. 또한 ETF 거래량 톱5 렌더러(`etfVolRow` / `byVol` top5, `renderEtf` 내부)는 이미 만들어져 있으나 홈 DOM에 `#etf-top-rows` 엘리먼트가 없어 사실상 유휴 상태다.

## 목표

①과 ②를 **하나의 블록**으로 통합하고, 그 안에 **거래량 톱5 ETF 행**을 신규로 배치한다. 섹터 로테이션·안전자산 선호도 블록은 그대로 둔다.

## 통합 후 구조

### 합친 블록 "ETF로 읽는 시황" (4개 층, 위→아래)

1. **헤드라인 카드** — 기존 `etf.lead.title` + `etf.lead.body` (변경 없음)
2. **베팅 흐름 게이지** — 분할바(하락 베팅%/저점매수%) + 팩트 2행(인버스 거래량 배수, 레버리지 등락률) + 노트. 기존 `#etf-betting` 렌더 그대로 유지.
3. **거래량 톱5 ETF 행** (신규 자리) — 순위·이름·거래량·등락률 실측 4요소.
4. **"ETF 전체 랭킹 →" 링크** — 합친 블록 맨 아래로 이동.

### 그대로 유지

- **섹터 로테이션** 블록 — 변경 없음.
- **안전자산 선호도** 블록 — 변경 없음. 단, 이 블록 끝에 달려 있던 "ETF 전체 랭킹 →" 링크는 제거(합친 블록으로 이전).

## 거래량 톱5 ETF 행 — 행 형식

각 행은 **실측 4요소**만 표시한다. 한 줄 "왜" 설명 문구는 붙이지 않는다.

```
[순위]  [이름]  [거래량]  [등락률]
  1    KODEX 인버스    12.4억주   +6.1%
```

- **순위**: 1~5. 상위 3개는 강조 색(`.rk.t`), 4~5는 muted.
- **이름**: ETF 이름.
- **거래량**: `manju()` 포맷(억주/만주). 실측.
- **등락률**: 색상 — 상승=빨강(`--up` #E03131), 하락=파랑(`--dn` #2775ED). 실측.
- **클릭**: **비활성**. 행은 정보 표시 전용이며 `onclick` 없음(`<a>` → `<div>` 또는 onclick 제거). 톱5는 임의 ETF라 상세 페이지가 없는 종목이 대부분이므로 etf-detail로 보내지 않는다.

### 데이터 소스

- ETF 목록: `SNAP.etfs`(stocks-snapshot.json) 또는 `/api/signals`의 etf 데이터. 기존 `renderEtf`/`renderTopsFromSnap`가 쓰는 것과 동일.
- 정렬: `vol > 0` 필터 후 `vol` 내림차순, 상위 5개(`byVol ... slice(0,5)`).
- 등락률: 각 ETF의 `change_pct`/`changePct`. 실측.

> SERVICE_RULES "실측만" 원칙 준수 — 모든 수치는 스냅샷/시그널 API 실측값. LLM 생성 문구·수치 없음. 헤드라인 카피만 기존 `etfLead` 룰 기반(변경 없음).

## 구현 범위

### HTML (`web/stocks/index.html` `.home-side`)

- 기존 블록 ⓪(시황)과 ①(베팅 흐름)을 **한 `.block`으로 병합**.
  - `block__h`는 시황 헤드(📊 ETF로 읽는 시황 + `#etf-upd-badge`) 유지.
  - 내부: `#etf-lead` → `#etf-betting` → **신규 `#etf-top-rows` 컨테이너** → "ETF 전체 랭킹 →" 링크.
- 블록 ③(안전자산)의 "ETF 전체 랭킹 →" 링크 제거.

### JS (`web/stocks/index.html`)

- `#etf-top-rows`를 거래량 톱5로 채우는 렌더링 배선. 이미 존재하는 `renderEtf`의 `byVol`/`#etf-top-rows` 로직을 활용하되, **행에 등락률 컬럼 추가**가 필요하므로 `etfVolRow`를 수정하거나 신규 행 함수를 만든다.
  - 행 형식: 순위 + 이름 + 거래량 + 등락률(색). 클릭 핸들러 제거.
- 홈 진입 시 `#etf-top-rows`가 채워지도록 호출 경로 확인(`renderEtf` 또는 `renderTopsFromSnap` 경유). 현재 `renderEtf`는 `if(w1)` 가드로 no-op 상태 → DOM 추가되면 자동 동작.

### CSS

- 거래량 톱5 행 스타일. 기존 `etfVolRow`가 쓰는 `.row`/`.rk`/`.barwrap`/`.barval` 클래스 재사용 가능 여부 확인. 사이드바 폭(좁음)에서 `.home-side .barwrap{display:none}` 규칙(line 145)이 걸려 있으므로, 거래량 바 대신 텍스트 거래량 + 등락률 레이아웃이 적합. 행 레이아웃은 시그널 랭킹 행(`.srk-row`) 스타일 패턴 참고.

## 검증

- node 테스트(`api/_signals-core.test.mjs`)는 데이터 계층(`etfBettingFlow`/`etfLead`) 변경이 없으면 그대로 통과해야 한다. 이 작업은 프런트 렌더링 변경이므로 코어 테스트 영향 없음.
- 로컬 미리보기로 합친 블록 렌더 확인: 헤드라인→게이지→톱5→링크 순서, 톱5 행 클릭 비활성, 등락률 색상, 섹터/안전자산 블록 위치 유지.
- 거래량·등락률이 스냅샷 실측값과 일치하는지 확인.

## 범위 밖 (YAGNI)

- 행별 "왜" 설명 문구 생성.
- etf-detail 상세 페이지 신규 작성.
- 섹터 로테이션·안전자산 블록 내용 변경.
- API/백엔드 변경 (데이터는 기존 소스 그대로).
