# 위로 한 줄 (comfort_line) — 설계

브리핑 근거 섹션 맨 아래에, 글을 읽는 투자자에게 건네는 순수 정서적 위로 한 줄을 추가한다.
5가지 서술 형식(bullet / why_what_so / scenario / qa / signal)은 건드리지 않고, 형식과 무관한 일관된 컴포넌트로 한 번만 붙인다.

## 목적

- 매일 예측·결과 숫자를 마주하는 독자에게 마지막에 한 줄의 정서적 공감을 남긴다.
- 형식별로 갈리지 않고 어떤 형식이 뽑혀도 같은 자리에 같은 모양으로 보인다.

## 적용 범위

- 세 브리핑 모두: 코스피 시초가(kospi) · 코스피 마감(close) · 미국 시장(us).
- 채널: 웹 페이지만. 텔레그램·이메일은 이번 범위 제외(구독 채널 노이즈 최소화). 추후 후속 과제로 텔레그램 1줄 추가 가능.

## 톤 경계

- 순수 정서적 위로만. 투자 조언·내일 전망·종목 추천 금지.
- 숫자·등락률·종목명·티커를 담지 않는다.
- 해요체 한 줄.
- 감성형과 담백형을 한 풀에 섞어 그날 톤(결과·확신도)에 따라 결을 고르게 한다. 하락·예측 빗나감엔 살짝 따뜻하게, 평온한 날엔 담백하게.

### 예시

| 맥락 | 문구 |
| --- | --- |
| 마감 하락 (감성) | 오늘 마음 졸인 만큼, 충분히 애쓰셨어요. 장 끝났으니 이제 좀 쉬어가요. |
| 마감 하락 (담백) | 오늘은 여기까지예요. 내일 또 열려요. |
| 마감 상승 | 잘 마무리된 하루예요. |
| 시초가 | 장이 곧 열려요. 너무 서두르지 않기로 해요. |
| 미국 밤 | 밤사이 시장이 뒤척여도, 당신의 잠까지 뒤척이진 않았으면 해요. |
| 예측 빗나감 | 맞는 날도 틀리는 날도 있어요. 오늘은 그런 날이에요. |

## 생성 방식

- AI 맥락 맞춤 생성. `call_claude.py`가 출력하는 analysis JSON에 최상위 필드 `comfort_line`(문자열 1개) 추가.
- 5가지 형식 분기와 독립 — 어떤 형식이 뽑혀도 항상 같은 방식으로 생성.
- 세 브리핑(kospi/us/close) 공통 규칙으로 프롬프트에 1곳씩 추가.

## 배치·렌더링

- 형식과 무관한 일관된 한 줄을 `reasons` 섹션 분기 블록 바로 아래에 한 번만 추가.
- 스타일: 시안 A — 상단 구분선 + `ti-mood-smile` 작은 아이콘 + 이탤릭 한 줄. 본문 분석과 시각적으로 분리된 "조용한 풋노트".
- 색은 기존 톤(상승 빨강 `#E03131` · 하락 파랑 `#2775ED` · 중립 회색)에 맞춘다.

### 구현 지점

- 새 파일 `scripts/templates/sections/_comfort_line.html` (시안 A 마크업).
- 주입점: 세 템플릿의 형식 분기 `{% if analysis_format ... %}{% endif %}` 바로 아래.
  - `scripts/templates/briefings/kospi.html`
  - `scripts/templates/briefings/us.html`
  - `scripts/templates/briefings/close.html`
  ```jinja
  {% if comfort_line %}{% include "sections/_comfort_line.html" %}{% endif %}
  ```
- `generate_html.py`의 `build_reasons()`가 `comfort_line`을 컨텍스트로 통과(한 줄 추가). 값이 없으면 `{% if %}`로 컴포넌트 자체 생략 — 빈 칸 없음.

## 검증·안전장치

- 파이프라인 순서 유지: `comfort_line`은 `call_claude --no-html`에서 생성 → `--render`에서 렌더. 검증 이후 출력물에만 반영.
- `validate_analysis.py`에 가드 추가: `comfort_line`에 숫자·`%`·종목 티커가 섞이면 통째로 제거(컴포넌트 생략). 환각 숫자 유입 경로 원천 차단.

## 변경 요약

- 필드 1개(`comfort_line`) 추가.
- 프롬프트 3곳 규칙 추가.
- 컴포넌트 1개 신규 + 템플릿 주입 3곳.
- 검증 가드 1개.
