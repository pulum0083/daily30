## 1. 목표

지금 대결판(§49)은 **코스피 등락률 · 외국인 누적 순매수 · 주도주 3종목 평균** 세 칸으로,
전부 "얼마나 올랐나" 한 축이다. 여기에 세 축을 더해 네 질문에 답한다.

| 축 | 질문 | 새로 붙는 것 |
| --- | --- | --- |
| 가격 | 오늘이 어제보다 센가 | (기존) |
| **강도** | 얼마나 뜨거운가 | 누적 거래량 · 일중 진폭 |
| **주도권** | 어디가 끄는가 | 코스피200·코스닥 · 섹터 대표 3종목 순위 |
| **누가** | 누가 사는가 | 기관 세부 6칸(금융투자·연기금·투신·은행·기타금융·보험) |

### 비범위

- 예측·전망. 판정은 "같은 시각 기준 실측 차이"만 말한다(§49 그대로).
- LLM 문장. 결론·배지·순위는 전부 결정론 규칙으로 만든다.
- 브리핑 페이지(`/briefings/`)·종목 상세 페이지 변경.

## 2. 측정으로 확정한 데이터 가용성

**전부 2026-09-16에 실제로 조회해 확인했다.** 추정이 아니다.

| 축 | 장 전 | 장중 | 마감 후 | 밤 | 주말(주간) |
| --- | --- | --- | --- | --- | --- |
| 가격 | ● | ● | ● | ● | ◐ |
| 강도 · 거래량 | ● | ● | ● | ● | ◐ |
| 강도 · 진폭 | ● | ● | ● | ● | **○** |
| 주도권 · 섹터 | ● | ● | ● | ● | ◐ |
| 누가 · 수급 | ● | ● | ● | ● | ● |

● 됨 · ◐ 저장된 공식 종가(`data/kr_official_closes.json`)에 의존 · ○ 안 됨

### 되는 것

- **코스닥·코스피200 1분봉** — 어제 날짜로 조회된다(`/chart/domestic/index/{KOSDAQ|KPI200}/minute`).
- **기관 세부 6칸** — 시간대별 매매동향 표 11칸 중 `v[3]~v[8]`. **이미 받아와서 버리고 있다**
  (`_vs-flow.parseInvestorTimePage`가 개인·외국인·기관계만 남긴다). 추가 조회 0.
  합 검증: 9/16 15:40 기준 세부 합 12,116 = 기관계 12,116.
- **수급 과거 날짜** — `investorDealTrendTime.naver?bizdate=`가 과거도 준다. 단 **페이지네이션**이라
  1페이지만 보면 빈손으로 보인다(조사 중 실제로 한 번 잘못 판단했다).
- **섹터 대표 3종목** — 종목 1분봉으로 직접 계산. 조회 8섹터 × 3종목 × 2일 = **48건**.

### 안 되는 것 — 대안 없음

- **원/달러 환율 분봉이 없다.** 일 단위만 있어(`front-api/marketIndex/prices`) "같은 시각" 축에 못 올린다.
  → 환율은 이번 범위에서 **제외**한다.
- **지수 거래대금(원)의 과거 시각이 없다.** `integration`의 `accumulatedTradingValue`는 현재값뿐이고,
  1분봉에는 거래**량**(천주)만 있다.
  → 화면 라벨을 **"거래량"**으로 쓴다. "거래대금"이라 쓰면 라벨과 실데이터가 달라 §0 위반이다.
- **1분봉은 약 7거래일까지만 온다.** 9/16 기준 9/8까지 391봉, 9/4는 0건.
  → 주말 주간 비교는 1분봉으로 못 한다. 진폭은 고·저가가 필요해 **주말엔 칸을 뺀다.**

## 3. 시간대별 비교 대상과 배치

### 3.1 비교 대상

| 시간대(KST 평일) | 비교 대상 | 근거 |
| --- | --- | --- |
| 장 전 07:30~09:00 | — (카드 없음) | 어제 확정값은 전날 밤에 이미 보여줬다 |
| 장중 09:00~15:30 | **오늘 확정 분 vs 어제 같은 분** | 네 축이 모두 살아 있는 유일한 구간 |
| 마감 후 15:40~17:00 | 오늘 정규장 최종 vs 어제 최종 | "같은 시각"이 "하루 전체"로 바뀐다 |
| 밤 17:00~다음 날 07:30 | 〃 (값 고정) | 코스피가 끝나 더 안 바뀐다 |
| 주말 | 이번 주(월~금) vs 지난주 | 1분봉 한계로 축소 |

**15:30~15:40은 공백이다.** 정규장은 끝났는데 확정 수급 행(15:31~15:40)이 아직 없다.
그 10분은 "집계 중"으로 두고 마감 후 카드를 만들지 않는다.

### 3.2 시간대별 새 카드 (사용자 확정)

| 탭 | 새 카드 |
| --- | --- |
| 장 전 | **없음** |
| 장중 | 결론(곡선) · 강도 · 주도권 · 수급 |
| 마감 후 | 결론(곡선) · 강도 · 주도권 · 수급 |
| **밤** | **강도 1장만** |
| 주말 | 주간 비교 1장(진폭 칸 제외) |

밤에 강도만 남기는 이유는 **거래량이 하루 총량이라 그날의 성격을 요약해주기 때문**이다(사용자 판단).
결론·주도권·수급은 마감 후 탭에서 이미 본 값이라 뺀다.

### 3.3 홈 블록 순서

주인공이 시간대마다 바뀐다. 나머지 순서는 지금 `/stocks/`와 같다.

## 4. 중복 해소 — 대결판은 "어제"만 말한다

LIVE 지수바와 대결판이 코스피 등락률·수급을 **둘 다** 보여줘서, 같은 지표가 한 화면에 다른 숫자로 뜬다.

| 구간 | 어긋나는 이유 | 실측 |
| --- | --- | --- |
| 장중 | LIVE는 실시간, 대결판은 확정 1분봉(약 2분 지연) | 13:24~13:30 사이 코스피 +1.04~+1.24% |
| 마감 후 | LIVE 바 수급에 애프터장이 섞인다(§51 남은 갭) | 확정 −11,863/+12,116/−16,825 vs LIVE −11,820/+12,173/−16,861 |

값이 틀린 게 아니다 — 13:28 LIVE `6,700.00 · +1.10%`는 확정 13:28 봉과 **정확히 일치**했다.

**해소: 대결판 근거 줄에서 오늘 값을 다시 적지 않는다.** "어제 이 시각엔 −0.78%였어요.
지금은 +1.81%p 더 높아요" 형태로 쓴다. 오늘 절대값은 LIVE 바가 단독으로 담당한다.

> 주도주 타일 가격은 §48 수정 덕분에 정규장 확정 종가와 **0원 차이로 일치**한다.
> 어긋나는 건 수급뿐이고, 그건 §51이 남긴 갭이라 이 작업과 별개로 처리한다.

## 5. 데이터 규칙

선행 설계 §6의 규칙을 그대로 따르고, 이번에 확인한 것을 더한다.

- **지수(코스피)의 기준가는 일봉 `day` 엔드포인트의 종가다.** §48의 "15:30 1분봉이 정본" 규칙은 애프터장이
  섞이는 **종목**에만 해당한다 — 지수는 애프터장 세션 자체가 없어 일봉 종가가 그대로 공식값이다. 2026-09-16
  마감 브리핑 발행값(6,717.97 ▲90.71)으로 역산한 9/15 기준가는 6,627.26으로 일봉 종가와 정확히 일치했고,
  같은 시각 1분봉은 6,627.24로 소수점에서 갈렸다(13:30 등락률 −0.77 vs −0.78, 표시 2자리 경계값).
  이 설계 문서에 처음 적었던 "1분봉으로 통일한다"는 이 검증 전의 잘못된 판단이었다 — `api/_vs-prices.mjs`의
  `prevClose(kind='index', ...)`는 처음부터 일봉을 썼고, 코드는 고치지 않았다.
- **차이는 반올림된 두 값을 빼지 않는다.** +1.04 −(−0.78) = 1.82가 되지만 실측 차이는 1.811%p다.
  미반올림 값으로 계산해 1.81%p로 표시한다.
- **마감 후 수급은 15:31~15:40 행**(§51). 이 규칙으로 뽑은 9/15 수급
  (외국인 −15,711억 · 기관 −9,040억 · 개인 +8,320억)이 **그날 마감 브리핑이 발행한 숫자와 정확히 일치**한다.
  코스피 마감 +1.37%(6,717.97)도 브리핑과 같다 — 규칙이 맞다는 교차 검증이다.
- **16:00 이후 실시간·일봉·토스는 애프터장 값이다**(§48). 마감 후 카드는 1분봉과 15:40 행으로만 만든다.
- **날짜 고정 조회**(§45). 어제 값은 그 날짜 행만 쓰고, 없으면 비운다. 최신 행으로 폴백하지 않는다.
- **거래량은 방향이 없는 양이다.** 상승/하락 색을 칠하지 않는다(중립 먹색).
  칠하면 "거래가 25% 줄었다"가 빨간 막대로 나와 반대로 읽힌다.

### 판정 임계 (결정론)

| 항목 | "비슷해요" | 셈 / 약함 |
| --- | --- | --- |
| 코스피·코스피200·코스닥 등락률 | 차이 ±0.3%p | 차이 > 0 → 셈 |
| 섹터 대표 3종목 평균 | 〃 | 〃 |
| 누적 거래량 | 차이 ±10% | 차이 > 0 → 더 붙음 |
| 일중 진폭 | 차이 ±0.3%p | 차이 > 0 → 더 출렁 |
| 수급(주체별) | 부호가 같으면 "같은 방향" | 부호가 바뀌면 "돌아섬" |

임계는 §49와 같은 값에서 출발한다. 한 달 운영 후 "비슷해요" 비율을 보고 조정한다.

### 섹터 평균의 한계 — 이름으로 드러낸다

대표 3종목 평균과 46종목 평균은 **순위가 갈린다.**

| | 46종목 | 대표 3종목 |
| --- | --- | --- |
| 1위 | 반도체 +2.16% | 전력기기 +2.50% |
| 2차전지 | 7위 −1.33% | 4위 −0.46% |

둘 다 실측이고 무엇을 평균 냈느냐가 다를 뿐이다. 조회량을 92건 → 48건으로 줄이려고 3종목을 택했으므로,
표 제목을 **"섹터 대표 3종목 평균"**으로 적고 각 행에 종목 이름을 함께 보인다.
"섹터 평균"이라 쓰지 않는다.

## 6. 화면·디자인 기준

**프로덕션 스타일시트를 그대로 쓴다** — `stocks-home.css` · `ds-subnav.css` · `vs-yesterday.css`.
(브리핑의 `style.css`는 `/stocks/`에서 쓰지 않는다. 팔레트도 다르다 — 종목 `--up:#E03131`/`--dn:#2775ED`.)

### 이미 있는 클래스를 쓴다

`vs-yesterday.css`에 대결판 어휘가 이미 있다. 새 카드는 그 위에 올린다.

`.vs-hero` · `.vs-card` · `.vs-card-h` · `.vs-stats` · `.vs-stat` · `.vs-stat-h` · `.vs-stat-r` ·
`.vs-pill` · `.vs-diff` · `.vs-lbl` · `.vs-lbl-s` ·
곡선은 `.vs-chartbox` · `.vs-chart` · `.vs-line-t` · `.vs-line-y` · `.vs-band` · `.vs-zero` ·
`.vs-rest` · `.vs-now` · `.vs-ytick` · `.vs-end` · `.vs-axis` · `.vs-legend`

### 새로 더하는 것은 `vsx-` 넷뿐

| 클래스 | 용도 |
| --- | --- |
| `.vsx-why` | 결론 카드의 근거 4줄(가격·강도·주도권·누가) |
| `.vsx-mini` | 0축 세로 막대 2칸 — 어제 옅게 · 오늘 진하게 |
| `.vsx-pairs` | 기관 세부 6칸 짝 막대 |
| `.vsx-tbl` | 섹터·시장 표 |
| `.vsx-sec` | 서브타이틀 위 구분선·간격 |

**기존 `vs-` 클래스는 건드리지 않는다.**

### 결론 카드는 곡선을 품는다

곡선과 결론 카드가 겹치므로 한 장으로 합친다 — **결론 한 줄 → 코스피 곡선 → 근거 4줄**.
곡선은 장중엔 정규장 전체를 축으로 두고 **확정 분 이후를 음영**으로 둔다.

### 수급 그래프는 세로 막대로 바꾼다

기존 `.vs-flow/.vs-ftrack/.vs-fbar`(가로 알약형)를 쓰지 않고 **0축을 가운데 둔 세로 막대**로 그린다
(사용자 결정). 기존 클래스는 남겨둬 되돌리기 쉽게 한다.
짝 막대 아래에는 **오늘과 어제 값을 함께** 적는다 — 오늘만 적으면 금융투자처럼 부호가 뒤집힌 항목의
변화가 안 읽힌다(−6,060억 → +7,605억).

### 인라인 스타일 금지

기존 블록에 인라인 스타일을 쓰면 프로덕션 CSS를 조용히 덮는다. 시안에서 실제로 두 번 겪었다 —
`#us-evening .ue-grid`(클래스를 빠뜨려 3열이 1열로), `.usw-tiles`(인라인 grid가 flex 가로 스크롤을 덮음).
**클래스를 그대로 쓰고 레이아웃을 인라인으로 지정하지 않는다.**

## 7. 오류·빈 데이터 처리

모든 실패는 **해당 칸·카드를 비우는 것**으로 수렴한다(§0).

| 상황 | 처리 |
| --- | --- |
| 어제 같은 시각 값 없음 | 그 칸 "어제 기록 없음", 판정 배지 생략 |
| 섹터 대표 3종목 중 일부 결측 | 있는 종목만으로 평균 내고 종목 수를 함께 표시 |
| 수급 합계 0 검증 실패 | 수급 카드 전체 생략 + 경고 로그 |
| 15:30~15:40 | 마감 후 카드 만들지 않음("집계 중") |
| 1분봉 조회 한계 초과(주말) | 저장소 값으로 대체, 진폭 칸 제외 |
