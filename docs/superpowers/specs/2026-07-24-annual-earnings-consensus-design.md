# 연간 실적 컨센서스 섹션 (종목 상세) — 설계

작성일 2026-07-24 · 대상 `web/stocks/{code}/` 종목 상세 페이지

## 배경·목적

경쟁력 점검 리포트([docs/reports/2026-07-21-kospilab-competitive-review.html](../../reports/2026-07-21-kospilab-competitive-review.html))가 지목한 "같은 3종목에서 밀리는 가장 큰 격차" — 경쟁사(코스피랩)는 종목 상세에 **연도별 영업이익 컨센서스**(25 확정 / 26·27 예상)를 보여주는데 우리 상세엔 없다. 목표주가만으론 "왜 그 가격인지"가 안 보이는데, 실적 추정치가 붙으면 근거가 생긴다.

핵심 전제: **실측 컨센서스 소스 확보가 선행**돼야 하고, 없으면 섹션 생략(운영규칙 0).

## 데이터 소스 (확보 완료)

이미 분기 재무를 뽑는 `m.stock.naver.com/api/stock/{code}/finance/quarter`와 **같은 계열**의 `finance/annual`이 연도별 매출·영업이익을 준다. 결정적으로 `trTitleList`의 각 연도가 `isConsensus: "Y"/"N"` 플래그를 달고 온다 — 어느 해가 확정이고 어느 해가 컨센서스(예상)인지 벤더가 명시한다.

- 제공 범위: **확정 3개년 + 컨센서스 1개년**(예: 2023·24·25 확정 + 2026 예상). 네이버가 미래 1개년만 줘서 경쟁사의 2개년(26·27)은 못 맞추지만, 현재 0개에서 크게 좁힌다.
- 값 단위: 억원(분기 재무와 동일). 확정 연도(2023~25)는 검증 시 실제와 정확히 일치.
- **컨센서스 값 크기는 손대지 않는다.** 삼성·SK하이닉스의 2026 컨센서스가 메모리 슈퍼사이클로 급등(삼성 영업 383조 등)하는데, 이는 라이브 분기 섹션이 이미 노출 중인 값과 정합하는 **벤더 실측 컨센서스**다. editorializing(크기 조정·상한)은 데이터 생성이므로 금지(운영규칙 0). 아래 sanity 게이트는 오직 **구조적으로 불가능한 값**만 거른다.

## 정합성 — sanity 게이트 (운영규칙 0)

연도별 각 항목에 대해, 구조적으로 불가능하거나 파싱 실패한 값만 폐기한다.

- `영업이익 > 매출` (영업이익이 매출을 초과할 수 없음) → 해당 연도 제외
- `매출 ≤ 0` 또는 매출·영업이익 파싱 실패 → 해당 연도 제외
- 유효한 연도가 하나도 안 남으면 **섹션 자체 생략**(억지로 채우지 않음)

컨센서스 값의 "공격적임"은 판단하지 않는다 — 급등도 벤더 실측이면 통과. 게이트는 데이터 오염(단위 깨짐·파싱 오류)만 막는다.

## 수집 파이프라인

### `scripts/build_stocks_snapshot.py`

- 신규 `parse_financials_annual(finance_info)` — `trTitleList`(각 `{isConsensus, title, key}`)와 `rowList`(매출액·영업이익)에서 연도별 `{year, rev, op, est}` 산출. `year = title[:4]`, `est = (isConsensus == "Y")`. 위 sanity 게이트 적용.
- 신규 `_naver_financials_annual(code)` — `finance/annual` 호출 후 `parse_financials_annual`. 실패 시 `[]`(기존 `_naver_financials`와 동일 패턴, 파이프라인 보호).
- **대상 3종목만 수집** — 모듈 상수 `ANNUAL_FIN_CODES = {"005930", "000660", "005380"}`로 게이팅. 스코프를 좁혀 QA를 단순화하고, 나머지 43종목의 컨센서스 품질을 검증하지 않은 채 노출하지 않는다.
- 스냅샷 레코드에 `financials_annual` 저장(3종목 외엔 키 없음/빈 배열).

### `scripts/generate_html.py`

- `build_stock_page` 컨텍스트에 `financials_annual` 전달(기존 `financials`와 동일 방식).

## 표시 (UI)

### `scripts/templates/stocks/detail.html`

분기 실적 차트(`fin-chart`) 컴포넌트를 **연도용으로 미러링**한 "연간 실적" 섹션.

- 위치: **분기 실적 섹션 바로 위**("연간 큰 그림 → 분기 최근" 흐름).
- 매출 = 막대 높이(연도 내 최대 매출 기준 정규화), 영업이익 = 하단 텍스트(음수는 `var(--dn)` 파랑), 확정 연도 = `fin-bar actual`(빨강 실선), 컨센서스 연도 = `fin-bar est`(빗금) + 캡션 "(E)" + 연도 라벨 `fin-x est`(파랑). 범례로 확정/추정 구분.
- 기존 fin-* CSS([web/assets/stocks.css](../../../web/assets/stocks.css)) 그대로 재사용 — CSS 추가 없음.
- `financials_annual`가 있고 비어있지 않을 때만 렌더(운영규칙 0 — 없으면 섹션 생략).
- 알려진 시각 특성: 컨센서스 급등 종목(삼성·하이닉스)은 2026 막대가 확정 연도를 납작하게 눌러 보인다. 이는 실제 매출 규모차의 정직한 반영이므로 왜곡 보정하지 않는다(사용자 승인 완료).
