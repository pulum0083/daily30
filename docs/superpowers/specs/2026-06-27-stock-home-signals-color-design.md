# 종목 홈 하단 — 색 절제 재설계 (비주얼 스펙)

작성 2026-06-27. 대상: 종목 대시보드 홈(`web/stocks/index.html`) 하단 신호 영역.
선행 스펙: [신호 분류 규칙 정의](2026-06-27-stock-home-signals-rules.md) — 신호 판정 로직은 그대로 두고, **표현(색)만** 재설계한다.

## 문제

현재 화면은 색이 동시에 여러 의미로 경쟁한다.

- **등락률** 빨강(상승)·파랑(하락) — 금융 관습.
- **신호 뱃지** 역행=주황, 외국인=파랑, 거래량=빨강, 신고가=보라, 기관=초록 — 신호 종류마다 고유색.
- 같은 빨강·파랑·초록이 "등락 방향"과 "신호 종류"라는 **다른 의미로 중복** 사용돼, 읽을 때마다 재해석이 필요하다.

## 원칙 — 색은 등락 방향 하나만

> **색(빨강·파랑)은 오직 "오르고 내림"을 뜻한다. 그 외 정보는 색으로 구분하지 않는다.**

이 화면에서 채도 있는 색이 허용되는 곳은 두 군데뿐이다.

1. **등락률 숫자** — 상승 `#E03131`(빨강), 하락 `#2775ED`(파랑).
2. **카드/행 좌측 방향 막대** — 3px, 상승 빨강·하락 파랑. 등락 방향을 한눈에 스캔하게 한다.

그 외 모든 요소(신호 뱃지, 메타 텍스트, 보조 설명)는 **무채색(회색 스케일)**로 처리한다. (확정 방향 = 브레인스토밍 옵션 B)

## A. 오늘의 특이 신호 — 신호 뱃지

| 항목 | 변경 전 | 변경 후 |
| --- | --- | --- |
| 배경 | 신호별 파스텔 컬러 (`#fff4e6`, `#e7f5ff` …) | 단일 회색 `#f2f4f6` |
| 글자색 | 신호별 채도색 (`#e8590c`, `#1971c2` …) | 회색 `#4e5968` |
| 모양 | pill(`border-radius:20px`) | 라운드 사각 `border-radius:6px` |
| 이모지 | 🔥🌏🏛️🏔️💰 각 뱃지 앞에 부착 | **제거** (색·시각 노이즈 감소, 글자로 구분) |
| 폰트 | `font-weight:700` | `font-weight:600`, `font-size:11px` |

- 신호 텍스트 자체(예: "거래량 ×3.2 급증", "외국인 순매수")는 [규칙 스펙](2026-06-27-stock-home-signals-rules.md)의 뱃지 문구를 그대로 쓴다. **앞의 이모지만 뗀다.**
- 행 좌측 막대: 상승 종목 빨강, 하락 종목 파랑. (역행 상승 종목의 빨강 막대가 폭락장에서 도드라지는 효과)

## B. ETF로 읽는 시황

- 상단 해석 박스(`인버스 거래량 급증…`): 본문 강조 숫자(`12.4억주` 등)에 채도색을 쓰지 않고 **회색 볼드**로. 박스 배경도 중립 회색 유지.
- 각 ETF 행 등락률(`+6.1%`, `−12.0%`, `+0.9%`)은 빨강·파랑 유지 — 색 = 방향 원칙과 일치.
- `거래량 1위` 같은 보조 뱃지/라벨: 회색 처리.

## 섹터별 보기 (칩)

- 네비게이션이라 구조는 유지. 칩 이모지는 종목 분류 아이콘(의미 색 아님)이므로 **유지**한다 — 색 절제 원칙의 대상이 아니다.

## 검증

- 신호 리스트 6행이 쌓였을 때 채도색이 등락률·방향 막대에만 존재하는지 시각 확인.
- 회색 뱃지가 종목명/등락률보다 시선을 끌지 않는지 (대비 위계: 등락률 > 종목명 > 뱃지 > 설명).
