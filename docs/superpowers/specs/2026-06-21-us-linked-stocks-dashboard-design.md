# 미국 연동 대표주 대시보드 — 설계 (반도체 칩보드 재설계)

작성일: 2026-06-21
대상: `web/stocks/index.html` 의 `#chips` 화면 ("AI 반도체 칩보드") 전면 교체
상태: 설계 확정 대기 → 스펙 리뷰 → 구현 계획(writing-plans)

## 1. 배경 · 문제

기존 "AI 반도체 칩보드"(`#chips`)는 한 화면에 *밤사이 미국 벨웨더 → SOX 추세 → 섹터 온도계 → AI 코멘트 → 실시간 포커스 토글 → 칩보드 매트릭스 → 주목 TOP3* 7~8개 개념이 겹쳐 핵심 메시지가 없다. "미국→한국 매핑 매트릭스"가 추상적이고 아침/마감 모드 분기까지 있어 이해가 어렵다. 또한 간판이 "반도체"인데 새로 넣을 현대차(자동차)와 맞지 않는다.

## 2. 개념 (한 줄)

**미국 시장에 민감한 한국 대표 수출주를, 각자의 "짝 벨웨더(미국 종목·지표)"와 묶어 보여주는 3종목(확장형) 대시보드.** 한국 장이 마감해도 미국 벨웨더는 실시간으로 계속 움직여, 마감 후에도 값 변동을 볼 수 있다.

- 메인 프레임은 "이 종목들"(종합 대시보드)이고, 실시간·마감후는 기능이다.
- 가칭: **미국 연동 대표주** (확정 전 working title).

## 3. 레이아웃 (A안 — 세로 스택 연동 카드)

```
[헤더]  🌐 미국 연동 대표주 · "장 마감 후에도 미국 벨웨더는 실시간"

[카드 N개 — 세로로 쌓음]
┌───────────────────────────────────────────────────────────┐
│ {종목명} [섹터] {코드}            [● 종가 06-19 | ● LIVE]  상세 →│
├──────────────── 한국 (좌 ⅔) ───────┬──── 미국 짝 (우 ⅓) ────┤
│ {가격}  {▲/▼ 등락%}                 │ 🇺🇸 짝 벨웨더 ● LIVE     │
│ [미니차트 5일]                       │ {벨웨더1}  {등락%}       │
│ [🔥거래량 ×N] [수급 칩…]            │ {벨웨더2}  {등락%}       │
│                                     │ {벨웨더3}  {값}          │
│                                     │ ───                      │
│                                     │ 💡 {연동 읽기 제목}       │
│                                     │ {연동 읽기 본문}          │
└─────────────────────────────────────┴──────────────────────────┘
```

- 좌 ⅔: 한국 종목 요약 (가격·등락·5일 미니차트·신호칩[거래량 급증·수급]).
- 우 ⅓: 짝 벨웨더 리스트(미국) + 연동 읽기.
- 카드 헤더의 `상세 →`는 기존 `/stocks/{code}/` 상세 페이지로 링크 (상세 중복 안 함).
- 모바일: 2단 → 1단 세로 스택.

확장형이라 종목이 늘면 카드를 더 쌓기만 하면 된다 (3-up 그리드보다 스케일 유리).

## 4. 데이터 모델 (확장형 config-driven)

```js
const LINKED_STOCKS = [
  { code:'005930', name:'삼성전자', sector:'반도체',
    bellwethers:[ {t:'MU', name:'마이크론', kind:'US'},
                  {t:'SOX', name:'필라델피아 반도체', kind:'INDEX'},
                  {t:'NVDA', name:'엔비디아', kind:'US'} ] },
  { code:'000660', name:'SK하이닉스', sector:'반도체',
    bellwethers:[ {t:'MU',...}, {t:'SOX',...}, {t:'NVDA',...} ] },
  { code:'005380', name:'현대차', sector:'자동차',
    bellwethers:[ {t:'USDKRW', name:'원/달러', kind:'FX'},
```

종목 추가 = 배열에 한 항목. 카드 렌더는 이 config를 순회.

## 5. 데이터 소스 (실측 — SERVICE_RULES 0번 준수)

| 항목 | 소스 |
| --- | --- |
| 한국 종가·등락·수급·거래량 | 토스 Open API (6자리 코드) |
| 미국 벨웨더 (NVDA·MU·TSLA) | 토스 Open API (티커 그대로) |
| 환율 USD/KRW | 토스 `/exchange-rate` |
| SOX(필라델피아 반도체 지수) | **미확정** — 토스 미제공 시 SOXX(ETF)로 대체하거나 항목 생략 |

- **연동 읽기는 벨웨더 방향에서 규칙 기반으로 생성하는 정성 문구.** 예: 벨웨더 2개 이상 동반 상승 → "갭업에 우호적". 예측 %·지어낸 숫자 금지. 화면에 찍히는 수치는 전부 실측.
- 실측 조회 실패 항목은 표시하지 않는다(빈 값/생략).

## 6. 실시간 · 마감 후 동작 (이 페이지의 핵심)

| 시간대 (KST) | 한국 영역 | 미국 벨웨더 영역 |
| --- | --- | --- |
| 한국 장중 09:00–15:30 | LIVE (토스 KR 폴링) | "어젯밤 종가" 고정 (미 장 마감) |
| 한국 마감 후 ~ 미 장 마감 | 종가 고정 + `종가 06-19` 배지 | **LIVE** (토스 US 폴링 30~60초) |

- "장 닫혀도 계속 움직임"은 마감 후 미국 벨웨더 LIVE에서 나온다.
- 폴링은 기존 허브의 라이브 패턴(/api 서버리스, sessionStorage)을 재사용. git 커밋으로 라이브 데이터 내보내지 않음.

## 7. 제거 항목 (YAGNI)

기존 `#chips`의 다음을 전부 제거하고 헤더 + 카드 스택만 남긴다.
- 🌅 아침 / 🌆 마감 모드 토글
- 어젯밤 미국 사이드 + SOX 추세 차트 사이드바
- 섹터 온도계, 실시간 포커스 토글
- 칩보드 매트릭스(`#chip-board`, `loadChipWidget` 매핑)
- 오늘 주목 TOP 3

허브의 hot 카드 문구("밤사이 미국 → 오늘 한국 반도체")도 새 개념에 맞게 교체.

## 8. 구현 순서

1. **프로토 (하드코딩 목업) 먼저** — 다른 종목 페이지와 동일 방식. config 구조는 위 §4 그대로 잡아 나중에 실데이터로 바로 연결.
2. 토스 실데이터 배선 (KR 종가/수급 + US 벨웨더 + 환율) — 후속.
3. 마감 후 LIVE 폴링 — 후속.

## 9. 성공 기준

- `#chips` 화면이 헤더 + 3개 연동 카드(삼성전자·SK하이닉스·현대차)로 렌더된다.
- 각 카드가 한국 요약(좌) + 짝 벨웨더·연동 읽기(우) 2단 구조다.
- config 배열에 종목을 추가하면 카드가 자동으로 늘어난다.
- 데스크톱 2단 / 모바일 1단으로 반응형 동작한다.
- 표시 수치는 (프로토 단계에선 일러스트, 실데이터 단계에선) 실측만 사용한다.

## 10. 미해결 / 확인 필요

- 페이지 이름 확정 ("미국 연동 대표주" vs 다른 톤).
- SOX 지수 데이터 소스 (토스 제공 여부 → SOXX 대체 or 생략).
- 현대차 짝 벨웨더 구성 확정 (환율·테슬라·S&P가 적절한지).
