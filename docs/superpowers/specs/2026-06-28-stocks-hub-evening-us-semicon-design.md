# 종목 허브: 저녁~새벽 "밤사이 미국 반도체 시황" 섹션

## 목적

종목 허브(`web/stocks/index.html`)의 `⚡ 상승 모멘텀 종목`(`#mom-track`)은 코스피 전용이라 장 마감 후엔 "장 마감"으로 멈춰 저녁~새벽 동안 죽은 공간이 된다. 이 시간대(17:00~익일 07:30 KST)에 그 자리를 **코스피 주도주와 연계된 미국 반도체 시황**으로 교체해, 다음 날 아침 브리핑(07:30 갱신) 전까지 살아있는 정보를 제공한다.

> 주의: 이 스펙은 브리핑 페이지의 `us_linked_story`(섹터→미국 이벤트 교체, `2026-06-24-us-linked-story-design.md`)와는 **다른 표면**이다. 본 건은 허브 대시보드의 `#mom-track` 영역 한정.

## 범위

- 대상 파일: `web/stocks/index.html` (섹션 마크업 + JS)
- 백엔드: `/api/stocks-live`는 이미 `us=` 파라미터로 미국 시세를 반환 → **변경 불필요**. 환율은 `/api/market` 기존 제공.
- 정적 폴백: `stocks-snapshot.json` 벨웨더에 반도체 종목 추가 필요(아래 8-2).
- 비범위: 자동차·로봇 등 타 섹터 연계(현대차 연계성 약해 제외), 생성형 코멘트/내러티브(실측만 표시).

## 시간 게이팅

| 시간대 (KST) | `#mom-track` | 저녁 미국 반도체 섹션 |
| --- | --- | --- |
| 07:30 ~ 17:00 | 표시 | 숨김 |
| 17:00 ~ 익일 07:30 | 숨김 | 표시 |

- 두 섹션 모두 DOM에 존재하고, 시간 게이트 함수가 `display`를 토글한다. **5분마다 재평가**(허브의 기존 `getKSTSlot`/`renderBriefStrip` 패턴과 동일).
- 경계: `hm = KST 시·분`. 저녁 섹션 노출 조건 = `hm >= 1020(17:00) || hm < 450(07:30)`.
- 주말: 미국장은 토·일 휴장(금요일 밤 = 토요일 새벽 KST가 마지막 거래). 토·일 저녁엔 직전 미국 종가(정적)를 표시한다. "생성 예정" 류 문구 금지.

## 표시 데이터

### 미국 반도체 종목 (8개) — 삼성전자·SK하이닉스 연계

| 표시명 | 티커 | 네이버 해외 심볼 | 비고 |
| --- | --- | --- | --- |
| 메모리·HBM | DRAM | `DRAM.K` | Roundhill Memory ETF · **선행지표 뱃지** |
| 브로드컴 | AVGO | `AVGO.O` | |
| 엔비디아 | NVDA | `NVDA.O` | |
| AMD | AMD | `AMD.O` | |
| 마이크론 | MU | `MU.O` | |
| ASML | ASML | `ASML.O` | ADR |
| 반도체ETF | SOXX | `SOXX.O` | iShares |
| 반도체ETF | SMH | `SMH.O` | VanEck |

- 각 행: 표시명 + 티커 + 가격 + 등락률.
- 등락 색: 상승=빨강, 하락=파랑(한국 관례).
- ⚠️ DRAM은 나스닥이지만 네이버는 `.K` 접미사로 조회된다(`.O` 409). 이 매핑을 정확히 둘 것.

### 매크로 스트립 (3타일, 실측)

- 원/달러 (환율, `/api/market`)
- 나스닥 QQQ (등락률, `QQQ.O`)
- 필라델피아 반도체 (대표 ETF SOXX 등락률 — 그리드의 SOXX와 중복 표기 허용. 스트립=한눈 요약, 그리드=개별 시세)

### 원화 / 달러 토글

- 종목 가격 표시 통화 전환. 기본 **원화**.
- 원화 = USD 종가 × **실시간 환율**(`/api/market` 원/달러). **하드코딩 금지.**
- 토글은 종목 가격에만 적용. 매크로 스트립의 원/달러 타일은 환율 그 자체.

## 데이터 흐름

```
초기 렌더(즉시): stocks-snapshot.json 벨웨더(정적 종가·등락률) + 마지막 환율
      → 그리드·스트립 즉시 표시(빈 칸 방지)
라이브 갱신: /api/stocks-live?us=DRAM.K,AVGO.O,NVDA.O,AMD.O,MU.O,ASML.O,SOXX.O,SMH.O
      + /api/market(환율·나스닥)
      → 미국 장중(대략 22:30/23:30~익일 05:00/06:00 KST)엔 실시간, 그 외엔 전일 종가
      → 폴링 주기 60초(미국 장중에만), 그 외 1회
```

- 정합성: 모든 수치는 실측(스냅샷 수집값 또는 stocks-live 실시간). 추론·하드코딩 금지(SERVICE_RULES 0 준수).
- 미국 장 개·폐장 판정은 단순화: stocks-live 응답값을 그대로 신뢰(별도 미국 캘린더 불필요). "전일 종가/실시간" 라벨은 시간대 기준 정성 표기.

## 레이아웃

- PC: 매크로 스트립(3타일) + 종목 **2단 그리드**(`grid-template-columns: repeat(auto-fit, minmax(250px,1fr))`).
- 모바일(<~560px): 자동 1단.
- 헤더: `🌙 밤사이 미국 반도체 시황 · 삼성전자·SK하이닉스 연계 · 17:00–07:30` + 우측 원화/달러 토글.
- 하단 캡션: "환율 N원 적용 · 미국 장 시작 전엔 전일 종가, 장중엔 실시간 · DRAM ETF는 메모리·HBM 선행지표".

## 컴포넌트 / 파일 변경

1. **`web/stocks/index.html`**
   - `#mom-track` 아래(또는 위)에 `#us-evening`(가칭) 섹션 마크업 추가. 초기 `display:none`.
   - 시간 게이트 IIFE: 5분마다 `#mom-track` ↔ `#us-evening` 토글.
   - `#us-evening` 렌더 IIFE: 스냅샷 즉시 렌더 → stocks-live·market 폴링 갱신 → 원/달러 토글 바인딩.
   - 종목 리스트는 **허브 인라인 상수**로 정의(전역 섹터 벨웨더를 건드리지 않음).
2. **`scripts/config/stock_universe.json`** (정적 폴백용, 선택)
   - semicon 섹터 `bellwethers`에 DRAM·AVGO·AMD·ASML·SMH 추가(기존 NVDA·MU·SOXX 유지, `bellwethers[0]`=NVDA 불변이라 종목 상세 벨웨더 영향 없음).
3. **`scripts/build_stocks_snapshot.py`**
   - 벨웨더 수집 시 종목별 네이버 해외 심볼 접미사 매핑 보강(특히 DRAM→`.K`). 스냅샷에 8종목 종가·등락률 포함.
   - 정적 폴백을 두지 않기로 하면 2·3은 생략하고 스켈레톤+라이브로만 동작(스코프 축소 옵션).

## 정합성·운영 규칙

- 라이브 서비스(`web/`) 변경이므로 사용자 명시 요청 하에만 커밋·푸시.
- 미국 종목 수치는 stocks-live(네이버 해외) 또는 스냅샷 실측만. LLM 생성 수치 금지.
- 환율 실시간(`/api/market`). 실패 시 마지막 스냅샷 환율로 폴백, 없으면 토글 USD만 노출하고 원화는 "—".

## 검증 기준

1. 17:00 경계 전후로 `#mom-track`↔`#us-evening` 토글 (시각 모킹으로 확인).
2. 원화/달러 토글이 8종목 가격을 환율로 정확히 환산(라운딩 포함).
3. stocks-live `us=` 응답으로 가격·등락률 갱신, 색상 규칙(상승 빨강/하락 파랑) 일치.
4. PC 2단 / 모바일 1단 반응형, 카드가 컨테이너를 넘지 않음.
5. 콘솔 에러 없음. 스냅샷만으로도(라이브 실패 시) 빈 칸 없이 표시.

## 비범위 (YAGNI)

- 미국 거래 캘린더(휴장일) 정밀 판정 — stocks-live 응답으로 충분.
- 종목별 미니 차트/스파크라인 — 1차 범위 외(추후).
- 자동차·로봇 등 타 섹터 — 연계성 확보 시 별도 검토.
