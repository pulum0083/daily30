# 코스피 방향 예측 — 선행신호 prior 기반 모멘텀 보정 설계

작성일: 2026-06-22
대상: 코스피 시초가 예측 브리핑(`type=kospi`) 한정. 미국·마감 브리핑은 범위 밖.

## 1. 배경과 문제

코스피 시초가 브리핑의 방향(`prediction.direction`)은 별도 모델이 아니라
`call_claude.py`의 프롬프트 우선순위 규칙(91-146행)을 LLM이 해석해 산출한다.
이 구조에서 LLM은 **전일 국내 등락(전일 코스피 종가)에 앵커링**하는 모멘텀 연속성 성향을 보인다.
±5~8% 휩소 국면에서 급락 후 V반등(예: 6/09 전일 -8.29% → 실제 +8.18%)을 구조적으로 놓친다.

### 정량 진단 (74거래일, 2026-03-05~06-22, `scripts/diagnose_direction_signals.py`)

코스피 D일 아침이 볼 수 있는 정보(D보다 엄격히 이전인 마지막 미국장 종가)만으로 방향 부호 적중률 비교.

| 규칙 | 전체(74일) | 충돌일(39일) |
| --- | --- | --- |
| SOX부호 | **70.3%** | — |
| 결합 prior | 67.6% | **66.7%** |
| 나스닥부호 | 66.2% | — |
| VIX 역부호 | 63.5% | — |
| EWY부호 | 62.2% | 61.5% |
| 모멘텀(전일 코스피) | **50.0%** | **38.5%** |

추가 발견 (구조 점검 중).
- `call_claude`는 LLM 입력에서 `market_data_js`를 제외한다(call_claude.py:1076). 그런데 **SOX·나스닥 지수·NQ/YM 선물은 `market_data_js` 안에만** 존재한다. 즉 프롬프트는 SOX·나스닥·선물을 우선순위 1~3로 지시하지만(115-120행) 그 숫자가 페이로드에 없다 — 단일 최강 신호 SOX(70%)를 모델이 보지도 못한 채 예측해 왔다. 컴포넌트 B의 prior 주입이 매 실행 이 값들을 텍스트로 명시하므로 이 갭도 함께 메운다.

핵심 결론.
1. **모멘텀(전일 코스피 부호)은 50.0% — 동전 던지기.** 모든 선행신호가 이를 크게 상회한다.
2. **충돌일(모멘텀≠EWY부호, 39일)에서 모멘텀은 38.5%로 동전보다 나쁘다.** V반등이 갈리는 바로 그 날 모멘텀 추종이 능동적으로 해롭다.
3. **SOX가 단일 최강(70%)** — 반도체 비중이 큰 코스피 특성. 가중치에서 SOX를 EWY 이상으로 둔다.
4. **강도 게이트가 실증적으로 필수.** 충돌일 중 EWY가 강할 때(|EWY|≥3.5%)는 9/9 전부 적중. EWY 오답은 전부 약신호(6/15·6/17·6/18, |EWY|<2.7%)에서 났고 그 사흘은 오히려 모멘텀이 맞았다. → **강한 prior일 때만 개입**하면 반전은 잡고 약신호 노이즈는 피한다.

### 한계 (정직한 명시)

- 백테스트는 실현 미국장 종가만 사용. **선물·뉴스는 복원 불가**(라이브는 포함되므로 라이브가 더 유리할 여지).
- **규칙**을 검증한 것이지 LLM 출력을 검증한 게 아니다.
- 74일은 변동성 큰 회복 국면 한 레짐 → 추세장 표본 부족.
- 부호만 보고 크기는 무시.

## 2. 목표

휩소·고변동 국면에서 V반등 같은 **방향 전환을 실제로 맞히는 것**(방향 적중률 개선).
추세장 정확도를 일부 내줄 수 있음을 감수하되, 강도 게이트로 그 손실을 최소화한다.

## 3. 설계

### 메커니즘 (기존 파이프라인 순서 유지)

```
call_claude --no-html    ← (B) 결정론 prior를 프롬프트에 주입 — 1차 교정
   → validate_analysis   ← (C) LLM 방향이 strong prior와 모순이면 개입 — 백스톱
   → call_claude --render → 발행
```

설계 원칙: **방향을 위(입력/프롬프트)에서 옳게 잡는다.** 그러면 LLM이 처음부터 일관된 산문을 쓰므로
산문 재생성 기계장치가 불필요하다. 게이트(C)는 LLM이 강한 신호를 무시한 드문 경우의 안전망이다.

### 컴포넌트 A — `scripts/leading_signal.py` (신규, 순수 함수)

- **입력**: `latest_kospi.json`의 이미 수집된 필드 — `ewy.change_pct`, `sox.chg`, `nasdaq.chg`, `nq.chg`(선물), `vix.change_pct`, `sp500.change_pct`, `dram_etf.change_pct`.
- **출력**: `{direction, score, strength, signals}`
  - `direction`: `'상승'|'하락'|'중립'` (score 부호 + 보합 데드밴드)
  - `strength`: `'strong'|'mid'|'weak'`
  - `signals`: 기여 신호 원본값(투명성·로깅용)
- **score**: 가중 합산. SOX·EWY 지배항, 나스닥·선물 보조항, VIX 역부호 확인항.
  초기값(진단 기반): `1.0*SOX + 1.0*EWY + 0.4*나스닥 + 0.3*NQ - 0.2*VIX`. **최종 가중치·임계값은 컴포넌트 D 백테스트로 확정.**
- **strength='strong' 조건(개입 자격)**: SOX·EWY 부호 일치 ∧ (|EWY|≥T_ewy ∨ |SOX|≥T_sox) ∧ VIX 강한 모순 없음.
  초기 임계값 T_ewy≈3.5%, T_sox≈3.0% (진단 근거) — 백테스트로 확정.
- 외부 의존성 없는 순수 함수 → 단위 테스트·백테스트에서 그대로 호출.

### 컴포넌트 B — 프롬프트 주입 (`call_claude.py`, `--no-html` 단계)

- 생성 직전 prior를 계산해 프롬프트에 **명시 규칙**으로 주입.
  - 계산된 prior 방향·강도·기여 신호를 텍스트로 제공.
  - 충돌 해소 규칙 추가: *"전일 큰 국내 급변동(±3% 이상) 다음날, 직전 미국장 선행신호(SOX·EWY·VIX)가 전일 국내 방향과 모순되면 — 그 신호들은 국내 마감 이후 정보를 반영하므로 — 선행신호 방향을 따른다."*
- 이게 1차 교정. LLM이 옳은 방향 + 일관된 reasons를 처음부터 생성하게 한다.

### 컴포넌트 C — 검증게이트 개입 (`validate_analysis.py`, 백스톱)

- prior를 **독립적으로** 재계산(A 호출). LLM 최종 `direction`이 **strong prior와 정반대**일 때만 발동.
  - 추세장·약신호에서는 미발동 → 추세장 정확도 무손상(진단 4번 근거).
- **발동 시 처리**: 산문 일관성을 위해 별도 템플릿 기계장치를 만들지 않고 **기존 생성 경로를 1회 재호출**한다 — `call_claude` 생성을 "방향=prior 방향 강제" 지시와 함께 다시 돌려 일관된 reasons·title·telegram_signals를 LLM이 새로 쓰게 한다. (개입은 드물므로 추가 API 호출 허용.)
- 재호출 후에도 모순이 남으면 발행은 진행하되 **관리자 텔레그램 알림**으로 로그(SERVICE_RULES 8 — 구독자 채널 발송 아님, 관리자 알림 한정).

### 컴포넌트 D — 백테스트 하니스 (`scripts/diagnose_direction_signals.py` → 확장)

- 이미 프로토타입 존재(74일 진단에 사용). 이를 확장해 **출시 게이트**로 사용.
- yfinance로 과거 N일 EWY·SOX·VIX·지수 복원 → A의 prior 계산 → 다음날 코스피 실제 부호와 대조.
- 비교군: prior vs 모멘텀 vs (가능 시) `briefings.json` 모델 실측.
- **출시 기준(제안)**: 결합 prior 방향 적중률이 모멘텀 베이스라인을 유의하게 상회 ∧ strong 개입 케이스의 오답이 허용 범위 이내. 가중치·임계값(T_ewy, T_sox) 손튜닝도 이 하니스로 수행.

## 3-b. 미국 브리핑 확장 (2026-06-23 추가, advisory 주입만)

미국 브리핑에도 같은 *논리*를 확장하되 **주입(advisory)만** 적용한다 — 하드 오버라이드는 넣지 않는다.

- **신호**: 프리마켓 선물(`futures.sp500_fut/nasdaq_fut/dow_fut.change_pct`) + SOX(`market_data_js.sox.chg`) + VIX. EWY는 한국 외국인 프록시라 제외. 모멘텀(배제 대상)은 전일 미국 현물 마감.
- **구현**: `leading_signal.compute_prior_us` / `format_prior_for_prompt_us`. `call_claude` US 경로에서 매 실행 주입(컴포넌트 B의 US판). validate 오버라이드·force_direction은 US 미적용.
- **오버라이드를 뺀 이유**: ① 미국은 선물(개장 전)과 예측 대상(같은 날 미국장)이 동일일이라 일봉 yfinance 백테스트로 임계값 검증 불가. ② 미국 브리핑은 정확도 77%로 모멘텀 부진이 진단된 적 없고, 프롬프트가 이미 선물을 1순위로 쓴다. 검증 안 된 임계값으로 라이브 방향을 강제 전환하는 리스크를 피한다.
- SOX가 US LLM 입력에서도 누락(market_data_js 제외)되던 갭을 prior 주입이 함께 보완한다.

## 4. 범위 밖 (YAGNI)

- 미국·마감 브리핑 미변경. 코스피 시초가 전용.
- 가중치 자동 학습/최적화 없음 — 백테스트로 손튜닝한 고정 가중치.
- 산문 재생성 전용 템플릿/모듈 없음 — 기존 생성 경로 재사용으로 해결.
- 레짐 분류기(추세장/휩소장 자동 판별) 별도 구현 없음 — 강도 게이트가 그 역할을 실용적으로 대체.

## 5. 검증 계획

1. A 단위 테스트: 6/09·6/22(강한 강세 prior), 6/15·6/17(약신호→strength≠strong) 입력으로 direction·strength 검증.
2. D 백테스트: 출시 기준 충족 확인 + 임계값 확정.
3. B·C 통합: 과거 강세 prior 날짜의 입력으로 `call_claude --no-html`를 돌려 방향이 prior와 일치하는지 확인(텔레그램 미발송).
4. 라이브 관찰: 배포 후 충돌일에서 개입 발동 여부·결과를 `briefings.json` 적중률로 추적.
